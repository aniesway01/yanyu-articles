# 烟台市民健康保 — 特药保障

> 数据来源: "烟台市民健康保"微信公众号，整理日期 2026-03-11

## 一、保障概览

"烟台市民健康保"设有两项特药/罕见病相关保障责任：

| 责任 | 名称 | 起付线 | 说明 |
|------|------|--------|------|
| **责任三** | 门诊特定高额药品 | **1.6万元**（年度累计） | 覆盖国内外特效抗癌药及罕见病用药 |
| **责任四** | 门诊特殊疗效药品 | **1万元**（年度累计） | 覆盖罕见病用药（如戈谢病）及苯丙酮尿症患者特殊食品 |

> 注：责任三和责任四属于门诊购药责任，单项责任起付线单独计算，不进行累计。

## 二、2026年度特药保障

> 来源: [2026年度烟台市民健康保产品说明书](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247506435&idx=2&sn=9b03a66a31b657db73e85d7375aaab7b&chksm=cedb372bf9acbe3ddb74f28006de3a7aa5a71b783781fda50460fb23423f130ff58f0f714985#rd)

### 参保资格（责任三、四共同前提）

保险期间内，满足以下条件之一的限定疾病被保险人方可适用：

1. 取得烟台市户籍满5年的限定疾病被保险人。
2. 取得烟台市户籍、年龄不满5周岁，其父母一方取得烟台市户籍满5年的限定疾病被保险人。

### 责任三：门诊特定高额药品费用保障

经烟台市基本医疗保险定点医疗机构特药责任医师诊断，使用符合《烟台市民健康保特定高额药品目录》中药品的，按照"理赔结算"流程在"烟台市民健康保"指定平台申请，且在基本医保定点医疗机构门诊或指定药店购买的特定高额药品费用：

| 项目 | 数值 |
|------|------|
| **起付线** | 年度累计 **1.6万元** |
| **报销比例（一般药品）** | 健康体 **70%**；非健康体 **50%** |
| **报销比例（普吉华/优赫得/倍利妥）** | 健康体 **30%**；非健康体 **20%** |
| **最高保额** | 保险年度累计 **50万元** |

> 备注：《烟台市民健康保特定高额药品目录》中药品涉及慈善援助的，应当按照慈善机构援助方案执行，由慈善机构援助的药品费用不纳入本产品理赔范围。被保险人可拨打客服热线 400-005-7995 联系理赔服务专员，协助进行慈善援助用药申请。

### 责任四：门诊特殊疗效药品费用保障

经烟台市基本医疗保险定点医疗机构特药责任医师诊断，符合使用《烟台市民健康保特殊疗效药品目录》中药品的，按照"理赔结算"流程在"烟台市民健康保"指定平台申请，且在基本医保定点医疗机构门诊或指定药店购买的特殊疗效药品费用：

| 项目 | 数值 |
|------|------|
| **起付线** | 年度累计 **1万元** |
| **报销比例** | 健康体 **70%**；非健康体 **50%** |
| **最高保额** | 保险年度累计 **30万元** |

> 备注：
> - 药品"维葡瑞"（戈谢病用药）仅负责保险期限内**首次确诊为戈谢病**且符合药品说明书适应症的患者，保险生效前已确诊者不承担赔偿责任。
> - 《烟台市民健康保特殊疗效药品目录》中药品涉及慈善援助的，相关费用不纳入本产品理赔范围，可拨打 400-005-7995 咨询。
> - **苯丙酮尿症患者特殊食品无免赔。**（见2025年度说明）

### 2026年度异地就医说明

- 被保险人异地就医使用特定高额药品目录及特殊疗效药品目录中的药品，经用药合理性审核通过后，纳入"烟台市民健康保"给付范围。
- **在烟台市外发生的异地就医医疗费用，各个报销比例均降低3个百分点。**

## 四、特药理赔方式

### 方式一：特药直付（推荐，无需垫资）

被保险人购药前，可先在"烟台市民健康保"微信公众号提交直付购药理赔申请，用药合理性审核通过后，**在指定药房购药，仅需支付个人承担部分**，不用垫付全额，无需跑腿。

1. 关注"烟台市民健康保"公众号
2. 提交特定高额药品直付理赔申请
3. 等待用药合理性审核通过
4. 前往指定DTP药店购药，只付个人自付部分

> 来源: [有了医保，还要买"烟台市民健康保"吗](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247499300&idx=1&sn=6c2e0ae060dace2ed91c55a4c19e542d&chksm=cedb130cf9ac9a1a8854b7554ed1d310d0fc99ba0f20a60ea21e2c2db52edfed8c375d9d1f66#rd)

### 方式二：事后报销（需垫资）

被保险人已提前在指定药房或就诊医院购药后，可在"烟台市民健康保"微信公众号上提交事后理赔申请，经用药合理性审核通过后，理赔款将汇入被保险人提供的银行账户内。

- **客服电话**：400-005-7995 / 400-182-6688
- **申请渠道**：微信公众号"烟台市民健康保"→ 菜单栏 → 理赔申请

> 注意：特定高额药品及特殊疗效药品必须在**指定药房或就诊医院**购买的费用，方可申请理赔。

### 2023年度特药理赔教程

> 来源: [2023年度烟台市民健康保特药理赔教程](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247489357&idx=2&sn=3a0e17a50da021017e467e9d8388c928&chksm=ced8fa65f9af737397ed7c747d401a2ea13c99f249de7ac3167c2adfdb03744cdd5abf20d05f#rd)

## 五、异地就医免申直赔

烟台市作为山东省试点城市，已打通省内异地结算理赔，实现**无感报销**：

- 参保人在**全省范围内**基本医保定点医疗机构就医，出示医保凭证即可直接结算
- 系统**自动**完成审核，无需主动申请、无需提交材料
- 从医保出院结算到理赔款拨付，整个流程**不超过3个工作日**
- 赔付资金直接汇入社会保障卡金融账户

> 背景：2025年底前，山东全省将全面实现商保省内异地和跨省异地免申直赔。
> 来源: [免申请、直接赔！山东定制型商业保险异地直赔首单出炉](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247503892&idx=3&sn=84a00b2a5aabfca228550e13f1d3933e&chksm=cedb3d3cf9acb42a5d630cd6243fe640ce5ac04d29f0a2fc3cf5a903afac6d8b8a09b90e1c4d#rd)

## 六、特药增值服务

### 1. 国内特药送药上门

直付理赔审核通过后，指定供应商安排专业服务人员提供DTP药店药品配送服务。

| 项目 | 说明 |
|------|------|
| **配送时效** | 同城：上午订单→下午送达；下午订单→次日上午送达 |
| **使用次数** | 保单有效期内不限次数 |
| **申请方式** | 公众号菜单栏 →【2025健管服务申请】→【国内特药送药上门】，或拨打 400-005-7995 |
| **所需材料** | 身份信息、处方及购药凭证（具体以通知为准） |
| **冷链费用** | 若需冷链运输，相关费用须被保险人自行承担 |

> 注：送药到达后，需提交身份信息及购药凭证，工作人员确认无误后方可领取药品。
> 来源: [出门买药难？奔跑吧药神‼️](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247501192&idx=1&sn=c1866781aa9c95e8ae7238dc0264c8b9&chksm=cedb28a0f9aca1b60c862a0f088abb815b710be73346cf99d3ad4a7f2c8cc87c6b427a04ae58#rd)

### 2. 全球找药服务

为罹患重疾的被保险人寻找特药购药渠道，包括：
1. **中国境内允许上市的新特药**（经国家药监局审批通过）
2. **国外最新特药**（通过海南国际医疗先行区预约购药）

| 项目 | 说明 |
|------|------|
| **服务次数** | 保单有效期内 **1次** |
| **反馈时效** | 申请后 **15个工作日**内反馈（人工检索模式） |
| **申请方式** | 公众号菜单栏 →【个人中心】→【2025健管服务申请】→【全球找药】 |
| **费用说明** | 仅提供**找药服务**，药品费、诊疗费、配送费等需被保险人自理 |

> 注意：一经预约成功，即计入权益使用次数，不可作废。
> 来源: ["一药难寻"？全球找药服务为您提交全新解决方案](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247501133&idx=2&sn=e6c04f3262f6f2d841a41f740305edd9&chksm=cedb2865f9aca17324c91388ce6c1674ea5df3f2ffd7e879c94bf81a90109651e876aa0eee2d#rd)

## 七、与基本医保的关系

- 烟台市民健康保的特药保障**覆盖医保范围外**的特效药品及高额用药，是基本医保的重要补充
- 2026年度保险期间：**2026年1月1日—12月31日**
- 2025年度保险期间：**2025年1月1日—12月31日**
- 参保价格：**139元/人/年**（未成年子女家庭同投可享99元/人优惠）
- **不限病史、不限健康状况**，带病可参保且可理赔
