# 烟台市民健康保 — 特药保障

> 数据来源: "烟台市民健康保"微信公众号，整理日期 2026-03-11

## 一、保障概览

"烟台市民健康保"设有两项特药/罕见病相关保障责任：

| 责任 | 名称 | 起付线 | 说明 |
|------|------|--------|------|
| **责任三** | 特定高额药品 | **1.6万元**（年度累计） | 覆盖国内外特效抗癌药及罕见病用药 |
| **责任四** | 特殊疗效药品 | **1万元**（年度累计） | 覆盖罕见病用药（如戈谢病）及苯丙酮尿症患者特殊食品 |

> 注：责任三和责任四属于门诊购药责任，单项责任起付线可年度累计。

## 三、特药理赔方式

### 方式一：特药直付（推荐，无需垫资）

被保险人购药前，可先在"烟台市民健康保"微信公众号提交直付购药理赔申请，用药合理性审核通过后，**在指定药房购药，仅需支付个人承担部分**，不用垫付全额，无需跑腿。

1. 关注"烟台市民健康保"公众号
2. 提交特定高额药品直付理赔申请
3. 等待用药合理性审核通过
4. 前往指定DTP药店购药，只付个人自付部分

> 来源: [有了医保，还要买"烟台市民健康保"吗](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247499300&idx=1&sn=6c2e0ae060dace2ed91c55a4c19e542d&chksm=cedb130cf9ac9a1a8854b7554ed1d310d0fc99ba0f20a60ea21e2c2db52edfed8c375d9d1f66#rd)

### 方式二：事后报销（需垫资）

适用于未选择直付服务的情形，参保人自行购药后通过公众号或客服电话提交理赔申请。

- **客服电话**：400-005-7995 / 400-182-6688
- **申请渠道**：微信公众号"烟台市民健康保"→ 菜单栏 → 理赔申请

## 四、异地就医免申直赔

烟台市作为山东省试点城市，已打通省内异地结算理赔，实现**无感报销**：

- 参保人在**全省范围内**基本医保定点医疗机构就医，出示医保凭证即可直接结算
- 系统**自动**完成审核，无需主动申请、无需提交材料
- 从医保出院结算到理赔款拨付，整个流程**不超过3个工作日**
- 赔付资金直接汇入社会保障卡金融账户

> 背景：2025年底前，山东全省将全面实现商保省内异地和跨省异地免申直赔。
> 来源: [免申请、直接赔！山东定制型商业保险异地直赔首单出炉](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247503892&idx=3&sn=84a00b2a5aabfca228550e13f1d3933e&chksm=cedb3d3cf9acb42a5d630cd6243fe640ce5ac04d29f0a2fc3cf5a903afac6d8b8a09b90e1c4d#rd)

## 五、特药增值服务

### 1. 国内特药送药上门

直付理赔审核通过后，指定供应商安排专业服务人员提供DTP药店药品配送服务。

| 项目 | 说明 |
|------|------|
| **配送时效** | 同城：上午订单→下午送达；下午订单→次日上午送达 |
| **使用次数** | 保单有效期内不限次数 |
| **申请方式** | 公众号菜单栏 →【2025健管服务申请】→【国内特药送药上门】，或拨打 400-005-7995 |
| **所需材料** | 身份信息、处方及购药凭证（具体以通知为准） |
| **冷链费用** | 若需冷链运输，相关费用须被保险人自行承担 |

> 注：送药到达后，需提交身份信息及购药凭证，工作人员确认无误后方可领取药品。
> 来源: [出门买药难？奔跑吧药神‼️](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247501192&idx=1&sn=c1866781aa9c95e8ae7238dc0264c8b9&chksm=cedb28a0f9aca1b60c862a0f088abb815b710be73346cf99d3ad4a7f2c8cc87c6b427a04ae58#rd)

### 2. 全球找药服务

为罹患重疾的被保险人寻找特药购药渠道，包括：
1. **中国境内允许上市的新特药**（经国家药监局审批通过）
2. **国外最新特药**（通过海南国际医疗先行区预约购药）

| 项目 | 说明 |
|------|------|
| **服务次数** | 保单有效期内 **1次** |
| **反馈时效** | 申请后 **15个工作日**内反馈（人工检索模式） |
| **申请方式** | 公众号菜单栏 →【个人中心】→【2025健管服务申请】→【全球找药】 |
| **费用说明** | 仅提供**找药服务**，药品费、诊疗费、配送费等需被保险人自理 |

> 注意：一经预约成功，即计入权益使用次数，不可作废。
> 来源: ["一药难寻"？全球找药服务为您提交全新解决方案](http://mp.weixin.qq.com/s?__biz=Mzg3Mzg1NjA3MQ==&mid=2247501133&idx=2&sn=e6c04f3262f6f2d841a41f740305edd9&chksm=cedb2865f9aca17324c91388ce6c1674ea5df3f2ffd7e879c94bf81a90109651e876aa0eee2d#rd)

协助参保人申请制药企业慈善赠药项目，减轻用药负担。

## 六、与基本医保的关系

- 烟台市民健康保的特药保障**覆盖医保范围外**的特效药品及高额用药，是基本医保的重要补充
- 2025年度保险期间：**2025年1月1日—12月31日**
- 参保价格：**139元/人/年**（未成年子女家庭同投可享99元/人优惠）
- **不限病史、不限健康状况**，带病可参保且可理赔
