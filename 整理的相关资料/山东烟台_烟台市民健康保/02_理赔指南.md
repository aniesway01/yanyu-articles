## 2026年度

### 一、保障责任概览（2026年度）

"烟台市民健康保"共设五项保障责任：

| 责任编号 | 保障内容 | 年度最高给付限额 |
|----------|----------|-----------------|
| 责任一 | 医保范围内住院自付费用保险金 | **150万元** |
| 责任二 | 医保范围外住院自费部分补充医疗保障保险金 | **100万元** |
| 责任三 | 特定高额药品（门诊）费用保险金 | **50万元** |
| 责任四 | 特殊疗效药品（门诊）费用保险金 | **30万元** |
| 责任五 | 健康管理服务 | 14项服务 |

### 二、理赔方式（2026年度）

#### 1. 本地就医 — 一站式结算

"烟台市民健康保"结算平台与烟台医保结算系统实现直联。**2026年1月1日0时起至2026年12月31日24时止**，烟台市基本医疗保险身份的被保险人在烟台市基本医疗保险定点医疗机构新发生的符合责任一、责任二理赔条件的医疗费用，在医院端可以与基本医疗保险、大病保险等**同步一站式即时结算**，无需额外申请。

#### 2. 异地就医 — 免申直赔 + 人工审核双模式

对于被保险人在异地（烟台市域外）医疗机构发生的符合责任一、责任二理赔条件的医疗费用，"烟台市民健康保"项目将**通过医保系统自动抽取被保险人的就医结算数据**，并结合保障政策核算本保险的赔付金额。

| 模式 | 条件 | 流程 |
|------|------|------|
| **免申直赔** | 符合"异地就医免申直赔"标准的被保险人 | 系统自动推送理赔结果，理赔款**优先拨付至被保险人本人的社保卡金融账户**，无需提交任何申请材料 |
| **人工申请** | 不符合直赔条件或被保险人主动申请 | 通过"烟台市民健康保"公众号或客服电话 **400-182-6688** 提出报案、上传理赔材料或邮寄至指定地址，也可到各区市指定理赔窗口递交材料 |

系统自动累计起付线，对于超过起付线应给予报销的被保险人，客服会联系被保险人补充提交银行卡等材料，进行审核报销。对达到理赔给付标准的需要提供纸质发票等，保险人将根据实际审核情况决定是否需要被保险人提供其他原件纸质理赔申请材料。

#### 3. 门诊特定高额药品（责任三）— 特药理赔

特定高额药品理赔分本地就医与异地就医两种情形，被保险人可根据实际购药情况选择：

| 方式 | 适用场景 | 流程 |
|------|----------|------|
| **直付购药（特药直赔）** | 有购药需求但尚未购买 | 先在"烟台市民健康保"微信服务号提交直付购药申请 → 经用药合理性审核通过 → 到特定高额药品**指定药房**购药时仅需支付个人承担部分 |
| **事后理赔** | 已在指定药房或就诊医院门诊购药 | 在"烟台市民健康保"微信服务号提交事后理赔申请 → 审核通过后理赔款汇入被保险人银行账户 |

- 特药直赔服务于2026年度**正式上线**，支持送药到家或到店领取。
- 2026年度特定药品目录请参阅《2026年度烟台市民健康保产品说明书》。
- 特定高额药品在指定药房或就诊医院购药发生的费用，方可申请理赔。
- 特药理赔咨询热线：**400-005-7995**

#### 4. 门诊特殊疗效药品（责任四）

参照责任三特定高额药品理赔流程。被保险人持药品处方、病历等理赔材料可在"烟台市民健康保"指定平台申请。如需协调异地用药时，由特殊疗效药品供应商提供服务，保证特殊疗效药品使用。

- 特殊疗效药品在指定药房或就诊医院购药发生的费用，方可申请理赔。
- 咨询热线：**400-005-7995**

### 三、理赔所需材料（2026年度）

| 就医类型 | 所需材料 |
|----------|----------|
| **本地就医** | 无需提供材料，一站式自动结算 |
| **异地就医** | 住院结算单原件、发票原件、住院病历、费用清单、理赔申请书、银行卡正反面复印件、身份证正反面复印件 |

**特殊情况额外材料：**

1. **单次理赔金额超过1万元**：根据人民银行反洗钱相关要求，被保险人需提供本人身份证件。
2. **被保人为未成年人**：法定监护人身份证件 + 关系证明；被保险人（或监护人）亲笔签署的授权委托书（须注明授权范围或事项）及委托双方身份证件。
3. **被保人身故**：被保险人医学死亡证明、受益人身份证明及第一顺位继承人关系证明；继承人之间授权委托书须注明授权范围或事项。
4. **委托他人申请理赔**：被保险人（或监护人）亲笔签署的授权委托书（须注明授权范围或事项）及委托双方身份证件。
5. **有其他商业保险或补助**：对方相关原件材料。

> 具体以实际发生情况为准。

### 四、关于使用社会医疗保险的约定（2026年度）

1. 未使用基本医疗保险报销的医疗费用，本产品不承担保险责任。
2. 在保险期间停止正常享受烟台市基本医疗保险待遇的，本产品不承担保险责任。
3. 因国家医保政策调整，特定高额药品、特殊疗效药品清单中的药品被纳入基本医疗保险支付范围的：若为住院用药，费用调整进入责任一或责任二，按保险责任进行报销，后续不再纳入责任三或责任四；若为门诊用药或院外用药，费用由基本医疗保险报销后，剩余个人负担费用再向责任三或责任四申请审核报销。
4. 保险期间内，被保险人由于工作等原因，基本医疗保险关系转至其他城市的，在保险期间内发生的约定范围内的合理医疗费用，经当地基本医疗保险报销后，可向本产品申请理赔。

### 五、责任免除（2026年度）

**下列情形，本产品不承担给付保险金的责任：**

1. 应当由第三人负担的；
2. 应当从工伤保险、长期护理保险、门诊统筹等给付的以及因生育住院产生的医疗费用；
3. 应当由公共卫生负担的；
4. 保险合同中载明的起付线以下金额；
5. 被保险人不按本市基本医疗保险有关规定就医发生的医疗费用；
6. 被保险人在医疗费用发生期间，不享受烟台市基本医疗保险统筹待遇的；
7. 当次手术或住院基本医疗保险整体不予给付的情形（如各种美容、整形、非功能性矫形、减肥，治疗雀斑、脱痣、护肤、镶牙、洁牙、种牙、配镜、装配义眼、假肢、助听器等）；
8. 非疾病治疗项目类（如各种健康体检、婚前检查、旅游体检、职业体检、出境体检等）；
9. 各种不育（孕）症、性功能障碍的诊疗项目，各种教学性、科研性和临床验证性的诊疗项目费用；
10. 法律、法规、政策、文件规定不予给付的事项。

**下列情形，申请特定高额药品或特殊疗效药品费用理赔，本产品不承担给付保险金的责任：**

1. 被保险人未在基本医保定点医疗机构门诊或指定药店购买的特定高额药品或特殊疗效药品的；
2. 责任四罕见病责任中药品维葡瑞仅负责保险期限内首次确诊为戈谢病且符合药品说明书适应症的患者购买此药的费用，保险生效之前就确诊的被保险人购买该药品的，本产品不承担赔偿责任；
3. 被保险人的疾病诊断及药品处方的开具与本产品特定高额药品目录及特殊疗效药品目录的药品说明书适应症不符；
4. 每次药品处方超过壹个月剂量部分的药品；
5. 被保险人的疾病诊断及药品处方的开具与国家药品监督管理部门批准的该药品说明书或目录中所列明的限定理赔范围约定用法用量不符；
6. 被保险人的疾病状况，经审核确定对药品已经耐药（耐药是指肿瘤病灶按照《实体瘤疗效评价标准RECIST》评价有进展的）而产生的费用；
7. 被保险人符合慈善援助用药申请，但因个人原因未提交相关申请或提交材料不全，导致援助项目申请未通过而发生的药品费用；被保险人通过援助审核，但因个人原因未领取援助药品，视为被保险人自愿放弃本合同项下适用的保险权益。

## 2025年度

### 一、保障责任详情（2025年度）

#### 责任三：门诊特定高额药品费用保障

**保障对象**（须满足任一条件）：
- 取得烟台市户籍满5年的限定疾病被保险人
- 取得烟台市户籍且年龄不满5周岁，其父母一方取得烟台市户籍满5年的限定疾病被保险人

**保障详情**：在保险期间内，经烟台市基本医疗保险定点医疗机构特药责任医师诊断，并使用符合《烟台市民健康保特定高额药品目录》的药品，且在基本医保定点医疗机构门诊或指定药店购药的费用，可申请理赔。

**赔付标准（2025年度责任三）：**

| 项目 | 标准 |
|------|------|
| 起付线 | 年度累计 **1.6万元** |
| 报销比例（普通目录药品） | 健康体 **70%**，非健康体 **50%** |
| 报销比例（普吉华、优赫得、倍利妥） | 健康体 **30%**，非健康体 **20%** |
| 年度赔付限额 | **50万元** |

**慈善援助说明**：目录内药品若涉及慈善援助，按援助方案执行，援助部分费用不予理赔。可拨打 **400-005-7995** 协助申请慈善援助用药。

**特药目录说明**：适应症以药品说明书为准；目录中标注"12"的为海外特药，需满足特定适应症且在**博鳌乐城指定医院就医**方可理赔。

如有疑问，欢迎拨打特药/罕见病药品理赔客服热线：**400-005-7995** 进行咨询。

### 二、理赔方式（2025年度）

#### 1. 本地就医 — 一站式结算

"烟台市民健康保"结算平台与烟台医保结算系统实现直联，**2025年1月1日0时起至2025年12月31日24时止**，被保险人在烟台市基本医疗保险定点医疗机构新发生的符合责任一、责任二理赔条件的医疗费用，在医院端可以与基本医疗保险、大病保险等**同步一站式即时结算**。

#### 2. 异地就医 — "免申直赔"试点服务

为贯彻落实山东省医疗保障局惠民保"免申直赔"试点工作安排，在烟台市医疗保障局指导下，正式推出异地就医**"免申直赔"试点服务**，实现"出院即理赔"，采用**"系统直赔+人工通道"双模式**。

对于被保险人在异地（烟台市域外）医疗机构发生的符合责任一、责任二理赔条件的医疗费用，被保险人可通过"烟台市民健康保"公众号或者客服电话 **400-182-6688** 提出报案、理赔申请，通过公众号上传相关理赔材料或邮寄到指定地址，也可以到各区市指定理赔窗口协助递交材料。系统自动累计起付线，对于超过起付线应给予报销的被保险人，客服会联系被保险人补充提交银行卡等材料，进行审核报销。

### 四、常见问题答疑（2024年度）

**Q: 理赔前需先经医保报销吗？**
需要。所发生的医疗费用需先经过基本医疗保险报销，再向"烟台市民健康保"申请理赔。

**Q: 理赔有次数限制吗？**
没有。符合理赔条件的医疗费用，保险期间内可多次申请理赔，直至达到对应保障责任的保额。

**Q: 意外伤害导致的医疗费用能报销吗？**
可以。因意外伤害（非第三方责任）导致被保险人在定点医疗机构发生的符合理赔条件的医疗费用，"烟台市民健康保"可以报销。

**Q: 有既往病史可以理赔吗？**
可以。"烟台市民健康保"是烟台市政府唯一认证可以理赔既往症的惠民保险产品，既往症患者也可按比例赔付。

**Q: 保险公司如何核查既往病史？**
保险公司可通过查医保卡就医记录、体检记录、同业理赔记录、委托第三方机构调查等方式了解参保人病史。**请勿故意隐瞒病史**，否则可能导致理赔调查延长甚至拒赔。

**直付购药领药流程：**

审核通过后，"烟台市民健康保"服务专员将电话联系被保险人选择领药方式：

2. **送药上门**：服务专员确认送药地址并发送领药凭证，配送员送药上门时被保险人需电子签署上述文件，并提供领药凭证与处方原件，仅需支付个人承担部分。

4. 依照保险法之规定，理赔申请人有义务真实地提供与确认事故的性质、原因、损失程度等相关的证明和资料。若伪造、变造与保险事故有关的证明、资料和其他证据，权益将会受到影响，并将承担相应的法律责任。

### 三、关于使用社会医疗保险的约定（2023年度）

1. 未使用基本医疗保险报销的，本产品不承担保险责任。
2. 若因政策调整，特定高额药品、特殊疗效药品清单中的药品被纳入基本医疗保险支付范围的，本产品责任三、责任四对经基本医疗保险报销后的费用继续承担给付责任。
3. 保险期间内，被保险人由于工作等原因，基本医疗保险关系转至其它城市的，被保险人在保险期间内发生的在本产品约定范围内的合理医疗费用，经当地基本医疗保险报销后，可向本产品申请理赔。

### 四、责任免除（2023年度）

**下列情形，本产品不承担给付保险金的责任：**

1. 应当由第三人负担的；
2. 应当从工伤保险、长期护理保险、门诊统筹等给付的以及因生育住院产生的医疗费用；
3. 应当由公共卫生负担的；
4. 保险合同中载明的起付线以下金额；
5. 被保险人不按本市基本医疗保险有关规定就医发生的医疗费用；
6. 被保险人在医疗费用发生期间，不享受烟台市基本医疗保险统筹待遇的；
7. 当次手术或住院基本医疗保险整体不予给付的情形（如各种美容、整形、非功能性矫形、减肥，治疗雀斑、脱痣、护肤、镶牙、洁牙、种牙、配镜、装配义眼、假肢、助听器等）；
8. 非疾病治疗项目类（如各种健康体检、婚前检查、旅游体检、职业体检、出境体检等）；
9. 各种不育（孕）症、性功能障碍的诊疗项目，各种教学性、科研性和临床验证性的诊疗项目费用；
10. 法律、法规、政策、文件规定不予给付的事项。

**下列情形，申请特定高额药品或特殊疗效药品费用理赔，本产品不承担给付保险金的责任：**

1. 被保险人的疾病诊断及药品处方的开具与特定高额药品目录及特殊疗效药品目录中，经国家药品监督管理局批准的该药品说明书的适应症及用法用量不符；
2. 每次药品处方超过壹个月剂量部分的药品；
3. 被保险人的疾病状况，经审核确定对药品已经耐药（耐药是指肿瘤病灶按照RECIST实体瘤治疗疗效评价标准有进展的）而产生的费用；
4. 被保险人符合慈善援助用药申请，但因个人原因未提交相关申请或提交材料不全，导致援助项目申请未通过而发生的药品费用；被保险人通过援助审核，但因个人原因未领取援助药品，视为被保险人自愿放弃本合同项下适用的保险权益。

## 背景知识：医保商保一体化平台

山东省医保商保一体化同步结算平台已全省上线。仅2024年度，山东省共有2,760.30万笔医保报销业务享受医保、惠民保"一站式结算"服务，惠及511.22万参保人，累计报销13.34亿元，实现"零跑腿""零等待""零垫资"。

烟台市医保商保平台通过以下技术支撑：

- **标准先行**：依据《基本医疗保险与定制型商业医疗保险"一站式"服务技术规范》统一标准
- **同步理赔**：打破医保部门、定点医疗机构和商保公司之间的数据壁垒，"医保+商保+自付"同步完成
- **可信共享**：运用大数据、区块链等技术，依托山东医保链实现数据可信共享
- **全程监管**：全程采集投保、理赔、结算等业务数据，建立完善监管机制

来源：国家医保局、烟台市医疗保障局

## 背景知识：三重医疗保障体系

"烟台市民健康保"作为商业补充保险，叠加在以下三重医疗保障之上：

| 层次 | 名称 | 主要保障内容 |
|------|------|-------------|
| 第一层 | **基本医疗保险** | 住院费用、门诊费用、药品费用等基本医疗费用补偿 |
| 第二层 | **大病保险** | 不限定病种；年度内累计超大病保险起付线部分自动纳入报销，实现一站式即时结算 |
| 第三层 | **医疗救助** | 针对特殊困难群体，经基本医保、大病保险支付后，个人负担的合规医疗费用按规定予以支付 |
