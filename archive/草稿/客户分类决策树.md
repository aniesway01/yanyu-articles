# 岩育健康 — 客户分类与服务决策树

> 用于首次接触时快速判断客户类型，匹配对应服务策略。

---

## 一、初始分类：两轴定位

### 轴 1：就医状态

```
客户就医状态？
├─ A. 未就医（有疑似症状）
├─ B. 未确诊（已就医但未确定病种）
└─ C. 已确诊（有确诊病历）
      → 收集：就诊时间、医院名称、病历
```

### 轴 2：保险状态

```
客户保险状态？
├─ X. 未投保
├─ Y. 已投保，未申请理赔
│     → 收集：保险公司、产品名称、投保时间、保险合同
└─ Z. 已投保，已被拒赔
      → 收集：以上 + 拒赔通知书、拒赔理由
```

### 组合矩阵

| | X 未投保 | Y 已投保未申请 | Z 已被拒赔 |
|---|---|---|---|
| **A 未就医** | 科普为主，引导投保 | 权益梳理 + 就医指导 | — |
| **B 未确诊** | 引导投保 + 就医注意事项 | 就医指导 + 提前准备材料 | 少见 |
| **C 已确诊** | 评估是否还能投保 | **核心服务对象** | **申诉服务对象** |

## 二、客户画像分类（按认知水平）

### 第一类：完全不懂型

| 编号 | 画像 | 核心需求 |
|------|------|----------|
| **1A** | 已就医，知道有保险，纯粹来问 | 全流程科普 + 材料代办 |
| **1B** | 已就医，尚未买保险，问保险有什么用 | 产品科普 + 引导投保 |
| **1C** | 纯咨询，问买了有什么好处 | 权益科普 + 增值服务展示 |

**应对策略：**
- 要求提供常规资料
- 科普合同条款 + 加值服务
- 告知可持续回来咨询
- **粘性维护**：基于健康资料主动告知注意事项，引导持续提供看诊资料

---

### 第二类：一知半解型

| 编号 | 画像 | 核心需求 |
|------|------|----------|
| **1D** | 自己研究过条款，知道基础材料，对流程有疑虑 | 流程确认 + 材料优化 |
| **1E** | 没研究条款，知道要交材料但不会申请 | 流程科普 + 代办 |
| **1F** | 被拒赔才来，只知道拒赔理由 | 拒赔分析 + 申诉指导 |

**应对策略：**
- 强调保司后台处置的不确定性 → 引导交由我们预审
- 对 1D：优化申报书
- 对 1E：科普流程 + 进一步告知权益
- 对 1F：科普流程 + 评估救济手段
- **粘性维护**：主动询问报销进度 + 推送健康权益

---

### 第三类：被拒客户

| 编号 | 画像 | 核心需求 |
|------|------|----------|
| **1G** | 完全不理解被拒原因，情绪大 | 情绪安抚 + 拒赔翻译 + 材料复核 |
| **1H** | 初步了解原因，不知如何申诉 | 可行性评估 + 申诉路径规划 |
| **1I** | 认知成熟，来要第二意见 | 专业核对 + 效率优化 |

**应对策略：**
- 对 1G：安抚情绪 → 把拒赔通知书翻译成白话 → 检查是否因材料不齐/录入错误导致误拒
- 对 1H：评估申诉可行性 → 规划路径（补病历 / 医生改描述 / 保司申诉 / 消保投诉 / 仲裁）
- 对 1I：核实理赔路径是否最优 → 告知代办可节省的时间和风险
- **粘性维护**：周跟踪机制 + 同病种理赔成功案例推送 + 政策变动预警

## 三、客户演变路径

```
首次接触（1A~1I）
       │
       ▼
   咨询 + 服务介入
       │
       ▼
 ┌─────┴─────────────────────────────┐
 │           可能转变                  │
 ├─ 2A：单次报销成功                   │
 ├─ 2B：单次报销失败 → 二轮服务        │
 ├─ 2C：长疗程首次报销成功              │
 ├─ 2D：长疗程首次报销失败 → 二轮服务   │
 └─ 2E：加购惠民保 + 使用增值服务       │
       │                              │
       ▼                              │
 ┌─────┴──────────────────┐           │
 │       最终转变           │           │
 ├─ 3A：长期客户            │           │
 │   主动提交资料            │           │
 │   健康管理全托付          │           │
 ├─ 3B：长期客户            │           │
 │   仅单次报销相关          │           │
 └─ 3C：未转化，流失        │           │
       └──────────────────┘           │
```

## 四、服务决策快速指南

```
客户来了
│
├─ 有保险合同吗？
│   ├─ 没有 → 科普产品 + 引导投保 → 标记 1B/1C
│   └─ 有 →
│       ├─ 申请过理赔吗？
│       │   ├─ 没有 →
│       │   │   ├─ 懂流程吗？
│       │   │   │   ├─ 懂 → 标记 1D → 预审材料 + 优化申报
│       │   │   │   └─ 不懂 → 标记 1A/1E → 全流程科普 + 代办
│       │   │   └─ 收集材料 → 进入「阶段 2：内部研究」
│       │   └─ 申请过，被拒了 →
│       │       ├─ 理解拒赔原因吗？
│       │       │   ├─ 完全不理解 → 标记 1G → 安抚 + 翻译拒赔书
│       │       │   ├─ 部分理解 → 标记 1H → 评估申诉可行性
│       │       │   └─ 清楚理解 → 标记 1I → 核对 + 优化路径
│       │       └─ 收集拒赔通知书 → 进入「阶段 2：内部研究」
│       └─ 收集保险合同 + 病历
│
├─ 已确诊吗？
│   ├─ 是 → 收集就诊时间、医院、病历
│   ├─ 未确诊 → 指导就医注意事项（医院资质、诊断书内容）
│   └─ 未就医 → 科普 + 建议就医路径
│
└─ 告知："2 天内反馈评估结果"
```

## 五、各阶段粘性动作清单

| 阶段 | 动作 | 目的 |
|------|------|------|
| 首次接触后 | 告知"下次理赔/换方案前先联系我们" | 锁定回头 |
| 材料提交前 | "材料发给我们预审一遍" | 建立依赖 |
| 理赔成功后 | 主动告知保单其他权益 + 推送增值服务 | 提升价值感 |
| 理赔失败后 | 周跟踪 + 同病种成功案例推送 | 维持信任 |
| 保单到期前 | 主动联系，推荐续保 / 复发险 | 续约转化 |
| 定期 | 推送健康权益（洁牙、癌筛等） | 即使没赔钱也觉得服务有用 |

## 六、情景模拟（训练用）

### Case 1：理赔前

> 患者刚确诊肺癌，有惠琼保 B 款，还没申请理赔。

→ 分类：1A（已确诊 + 已投保未申请 + 不懂流程）
→ 动作：收集合同 + 病历 → 匹配特药目录 → 指导特药直付申请 → 预审材料

### Case 2：理赔中

> 患者已提交理赔申请，等待中，来问进度。

→ 动作：追踪进度 → 告知时效（10/30 日）→ 如有延迟，联系保司/TPA

### Case 3：理赔后（被拒）

> 患者被拒赔，理由是"非医保目录内药品"。

→ 分类：1H（部分理解原因）
→ 动作：核实拒赔理由 → 检查是否属于特药目录 → 如属于，补充适应症材料申诉 → 如不属于，解释并引导使用其他权益
