# 岩育健康 — 惠民保代理赔服务 SOP

> 本文档整合自内部会议笔记与已有产品服务流程，适用于所有惠民保项目。
> 产品专属细则见：`惠琼保服务流程.md`、`烟台市民健康保险服务流程.md`

---

## 一、服务定位

- 我们是**保险理赔咨询公司**，不是法律公司、不是保险公司。
- 核心价值：帮助保户**最大化理赔成功率**，降低因不懂规则导致的拒赔。
- 长期目标：成为保户的**健康管理代办**，每次报销前帮他复核一遍。

---

## 二、客户来源

| 渠道 | 说明 |
|------|------|
| 医生转介 | 医生直接告知患者可咨询我们 |

## 三、服务全流程（6 阶段）

### 阶段 1：首次接触（当天）

**目标**：建立信任 + 收集基本信息

1. **开场白**
   > "XXX 您好，这里是岩育健康，我们的业务是提供保险理赔的咨询服务。这一轮对话主要了解您的基本情况，评估完后会进一步联系您。请问您目前遇到什么问题？"

2. **拉企业微信群**（客户 + 岩育专员）

3. **告知保密条款**，提升信任感（如客户要求，提供隐私告知书）

4. **信息收集清单**

   | 项目 | 具体内容 |
   |------|----------|
   | 当事人确认 | 是保户本人还是家属代办？ |
   | 就医状态 | 未就医 / 未确诊 / 已确诊（哪家医院？） |
   | 保险状态 | 未投保 / 已投保未申请 / 已投保被拒赔 |
   | 保险详情 | 哪家公司？什么产品？投保时间？ |
   | 保险合同 | PDF 或照片 |
   | 病历资料 | 确诊书、住院病历、门诊病历（尽量完整） |
   | 医生原话 | 请客户转达医生对病情的描述 |

5. **告知后续流程**："我们会在 2 天内反馈评估结果。"

6. **初步建议**：务必在指定类型医院（二级及以上公立医院普通部）就诊。

---

### 阶段 2：内部研究与评估（1-2 天）

**目标**：形成理赔方案

1. **研究保险合同**
   - 找出支持/不支持理赔的条款
   - 确认免赔额、赔付比例、健康体 vs 既往症分级
   - 确认客户投保的是哪个款别（基础 / 含特药）

2. **评估客户状态**
   - 所属客户画像分类（见「客户分类决策树」）
   - 判断理赔成功率
   - 评估合理理赔金额与可报销项目

3. **团队内部讨论**
   - 疑难 case 提前与保司理赔团队负责人做具体讨论
   - 确认客户适应症与可报销药物的匹配

---

### 阶段 3：反馈客户（第 2-3 天）

**目标**：提供专业建议 + 锁定长期服务关系

1. **告知理赔评估结果**
   - 可申请理赔的项目
   - 预估理赔金额
   - 就医需注意的事项（医院资质、异地备案等）

2. **告知额外保单权益**（增值服务、健康管理等）

3. **操作教学**
   - 线上理赔提交流程（公众号路径）
   - 特药直付/直赔申请方式
   - 一站式结算提醒（本地定点机构）

4. **植入长期服务钩子**（关键）
   - "下次报销前可以先把材料发给我们，我们帮您预审一遍。"
   - "有新的治疗方案前，可以先跟我们确认哪些药品在报销范围内。"
   - **不要做成问答模式**，而是让客户形成"每次理赔前先找我们"的习惯。

---

### 阶段 4：理赔执行支持

**目标**：确保材料一次通过

1. **理赔材料预审**
   - 定制个人专属材料清单（基础 + 特殊情况）
   - 客户上传前代为检查：凭证清晰、单据完整、适应症匹配
   - 如有二次报销，提醒保留分割单原件

2. **特殊情况处理**
   - 材料遗失：病历可补，发票可电子化
   - 既往症隐瞒风险：提前告知客户如实提供
   - 指定适应症：确认客户提供了正确的病历（不只是手边有的）

3. **与保司预沟通**（需要时）
   - 跟保司/TPA 做事前沟通，提前了解理赔态度
   - 对于模糊 case，请医生出具情况说明
   - 保司同意 → 推进；有异议 → 准备申诉材料

4. **代办提交**
   - 线上提交（公众号 4 步骤）或线下递交/邮寄
   - 为不会操作手机的客户全程代办

---

### 阶段 5：理赔后跟踪

**目标**：闭环 + 处理纠纷

1. **进度追踪**
   - 常规案件 10 日核定，复杂案件 30 日核定
   - 主动向客户反馈进度

2. **结果解读**
   - 拆解理算过程（免赔额扣除、比例核算、既往症降幅）
   - 很多客户觉得"赔少了"，需要专业解释

3. **拒赔申诉**
   - 拒赔通知书解读
   - 判定保司是否存在核算错误或条例误读
   - 补充材料申诉 / 消保投诉 / 仲裁建议

4. **医生协作**
   - 如需要，请医生补开/修改情况说明
   - A 医院或 B 医院开具均可
   - 长期目标：成为医生的商保理赔助手

---

### 阶段 6：长期维护

**目标**：客户粘性 + 转化

1. **定期跟进**
   - 过一段时间主动询问报销进度
   - 惠民保到期前主动联系，推荐续保或复发险

2. **健康管理推送**
   - 基于已提交的健康资料，主动告知注意事项
   - 推送健康使用权益（洁牙、癌筛、心理咨询等）

3. **增值转化**
   - 推荐复发险（何总与保险公司沟通中）
   - 根据客户状态推荐合适的其他产品

## 四、关键话术原则

| 原则 | 说明 |
|------|------|
| 不做问答 | 不是客户问一句答一句，而是主动告知 + 引导下次回来 |
| 强调不确定性 | "保司后台处置有不确定性，交给我们预审可以降低风险" |
| 锁定下次 | 每次服务结束都告知"下次理赔/换方案前先联系我们" |
| 匹配需求 | 按客户需求深浅提供对应服务（审核材料 vs 简单答疑） |
| 隐私合规 | 涉及病历等敏感资料，告知客户"允许理赔相关人员使用" |

---

## 五、与保司协作流程

```
我方评估 case → 与保司理赔负责人预沟通
  ├─ 保司同意 → 推进理赔
  ├─ 保司有异议 → 回复处理（补材料/改说明）
  └─ 保司不回复 → 视为默认同意，直接推进
```

- 对于条件合适的客户：大多是直付模式（二维码 → 药店领药）
- 对于不确定的 case：提前让药厂 TPA 介入协商
