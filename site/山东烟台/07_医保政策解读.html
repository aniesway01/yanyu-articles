一、基本医保制度概述

1.1 什么是基本医疗保险？

基本医疗保险由国家、单位、个人共同缴费，设立互助共济基金，对参保人的医疗费用进行补偿，避免"因病致贫"。

险种 参保对象 缴费方式
职工基本医疗保险 在职职工、退休人员 用人单位 + 个人按月缴纳
城乡居民基本医疗保险 农村居民、城镇非从业居民、在校学生、持居住证非户籍人员 个人缴费 + 政府财政补贴
灵活就业人员 灵活就业人员 自愿参加职工医保或居民医保，个人缴纳

重要提示：参保群众只可参加一种基本医疗保险，不得重复参保。

二、医保报销范围与不予报销情况

2.1 可报销范围（医保三大目录）

目录 说明
医保药品目录 甲类：全额纳入报销范围，按比例报销；乙类：个人先自付一定比例，剩余部分按比例报销
诊疗项目目录 临床必需、安全有效、费用适宜，且已制定收费标准的诊疗项目
医疗服务设施目录 定点医疗机构提供的诊断、治疗和护理过程中必需的服务设施

2.2 不予报销的六种情况

情况 说明
工伤 被认定为工伤的，由工伤保险承担，医保不重复报销
第三方责任 交通事故、打架斗殴等，由责任方承担；找不到人或拒赔，医保可凭法院判决书先行垫付后追偿
公共卫生服务 政府免费提供的疫苗接种（一类疫苗）、传染病防控等，由财政承担
境外就医 仅限国内（不含港澳台）就医，境外自费
体检及养生保健 常规体检、推拿按摩、保健品等非治疗性项目不予报销
超出医保目录 目录外药品、诊疗项目须自费；起付线以下及超过封顶线部分须自费

五、门诊慢特病政策

5.1 什么是门诊慢特病？

门诊慢特病（简称"慢特病"）是指经医疗保障经办机构确认备案，需要长期门诊治疗，其费用由统筹基金按规定比例支付的部分疾病。

  • 甲类病种：不限种数
  • 乙类病种：最多可认定 2 种；同类型（互斥病种）不得重复办理；每年度可变更一次（当年度未发生相关费用前提下）

5.2 不予报销的费用

  1. 住院治疗、医疗专护期间发生的费用
  2. 与认定病种无关的治疗及检查检验费

5.3 申办流程

申办材料：身份证或社会保障卡 + 近一年内病历材料原件或有效复印件（包括住院病历、门诊病历、相关检查报告）

申办途径：

途径 适用情况
定点医疗机构办理 在确诊定点医疗机构医保办提交材料，由副主任医师以上填写申请表
网上办理 适用于异地医疗机构确诊的9类特定疾病（白血病、恶性肿瘤等），通过"烟台市政务服务网"在线提交
邮寄办理 异地居住或确诊患者，可将申办材料快递至参保地医保经办机构
医保经办机构办理 以上方式均无法办理时，持相关证件到参保地医保经办机构办理

待遇起始日期：
- 经住院治疗确诊：出院日期次日起
- 经门诊治疗确诊：确诊当日起
- 超出病历材料时限申办：申办当日起

六、个人账户与个账共济

6.1 职工医保个人账户用途

  1. 支付定点医疗机构门诊和住院个人自付费用（美容、健美等非疾病治疗除外）
  2. 支付定点医疗机构预防性免疫疫苗费用（包括所有二类疫苗）
  3. 在健康体检定点医疗机构支付健康体检费用
  4. 在定点零售药店购买药品（准字号药品、中药饮片）、医疗器械、消毒用品
  5. 购买与职工医保相衔接的商业健康保险产品（包括"烟台市民健康保"）

注意：个人账户资金不得用于公共卫生费用、体育健身、养生保健消费、健康体检等不属于基本医保保障范围的支出。

6.2 个账共济规则

功能：职工参保人通过绑定近亲属（配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女），允许家庭成员使用本人个人账户余额支付其就医购药时的个人负担费用。

绑定规则（单向绑定）：
- 一个被共济人只能接受一个共济人的绑定
- 一个人只能同时拥有共济人或被共济人一个身份，不能同时兼任两个身份

操作方式：
- 关注"烟台市医疗保障局"微信公众号 → "医保服务" → "办事大厅" → "个账共济" → "添加家庭成员"
- 就医时持被共济人的医保码/身份证/社保卡，即可使用共济人个账余额结算

用个账给家人缴纳居民医保：需先在"烟台市医疗保障局"微信公众号完成个账共济绑定，再通过"山东税务社保费缴纳"微信或支付宝小程序缴费。

七、医保码使用指南

7.1 什么是医保码？

医保码即医保电子凭证，是国家医保信息平台统一签发的参保人唯一身份识别电子介质，是全国医保线上业务的唯一身份凭证。目前烟台市已有 640万人 激活医保码。

7.2 主要使用场景

  1. 定点医疗机构挂号就诊、支付医药费、入院/出院结算（替代实体卡）
  2. 定点零售药店购药，使用个人账户金支付
  3. 通过"亲情账户"绑定，帮老人/儿童展示医保码就医购药
  4. 通过"个账共济"绑定，实现个人账户余额家庭共用
  5. 支持全省异地医保个人账户通刷

7.3 激活方式

  • 国家医保服务平台 APP
  • "烟台市医疗保障局"微信公众号 → "医保服务" → "医保电子凭证"

7.4 忘记支付密码 / 密码被锁定

八、职工长期护理保险（长护险）

8.1 基本介绍

职工长期护理保险（长护险）是以社会互助共济方式筹集资金，对因年老、疾病、伤残等原因导致长期丧失自理能力、经评定达到一定护理需求等级的参保职工，提供基本生活照料和医疗护理的社会保险制度。

覆盖范围：参加职工基本医疗保险的职工和退休人员，均纳入覆盖范围。

8.2 筹资标准

来源 金额
职工基本医疗保险统筹基金 60元/人/年
财政补助 5元/人/年
福彩公益金 5元/人/年
个人缴费 30元/人/年（从个账一次性划拨；无个账者个人缴纳）
合计 100元/人/年

8.3 保障方式

保障方式 说明
医疗专护（专护） 定点医护机构医疗专护区，24小时连续医疗护理
医养院护（院护） 定点医护机构医养院护区，24小时连续在院照护
巡查护理（巡护） 定点医护机构定期指派人员，居家巡诊照护

8.4 费用结算标准

基础护理费用（按床日定额）：

服务类型 失能等级3级 失能等级4级 失能等级5级
专护（二级及以上医疗机构） 170元/天 190元/天 210元/天
专护（一级医疗机构、护理院） 130元/天 150元/天 170元/天
院护 30元/天 40元/天 50元/天
巡护（月限额） 600元/月 800元/月 1000元/月

合并甲类门诊慢特病的专护患者，额外补偿 10元/人/天。

日常照护费用：以"照护服务包"形式打包付费，600元/人/月，个人不承担照护服务包费用。

个人自付比例：基础护理费用个人负担 10%，长护险资金负担 90%。

8.5 失能等级划分

失能等级分为六级：0级（基本正常）、1级（轻度失能）、2级（中度失能）、3级（重度I级）、4级（重度II级）、5级（重度III级）。

享受长护险待遇须为重度失能（3-5级），评定通过后，自办理建床登记手续之日起享受待遇。

8.6 申请方式

  • 现场申请：携带参保人及代办人身份证、病历等材料，到所选定点医护机构申请
  • 线上申请（本人）：

  • 线上申请（家属代办）：使用家属手机，通过"山东长护险"小程序 → 失能申请代办

异地常住人员：申请时"是否异地长期居住"选择【是】，流程相同，可全程线上办理。

受理时限：承办机构受理后 9个工作日内 组织专家完成评定。

十、医保账户安全

10.1 个人账户被盗刷后的处理步骤

  1. 立即向公安机关报案，保存被盗刷金额、交易记录等证据
  2. 联系属地医保部门，反映情况；医保部门可对个账进行临时冻结
  3. 立即挂失医保卡；如医保码已泄露，马上更改支付密码
  4. 修改密码：避免使用简单数字、生日、身份证号等，不向他人透露

10.2 防骗提示

不法分子常利用"医保停用"等名义发送诈骗短信。切勿向陌生人提供验证码、密码、面部识别、手机共享、身份证号码、银行卡账号密码等信息。

十一、国家及省级医保政策动态

11.1 2025年医保主要政策方向

  • 集采：2025年上半年开展第11批药品集采，下半年开展第6批高值医用耗材集采；2018年以来集采累计节省医保基金约4400亿元
  • 跨省异地就医：2024年跨省异地就医直接结算达 2.38亿 人次，减少垫付资金 1947亿元；2025年将继续扩大覆盖范围，巩固门诊慢特病跨省直接结算
  • 个人账户跨省共济：2025年1月已有11省份81统筹区开通，全年将加快扩展
  • 丙类药品目录：第一版丙类目录计划2025年内发布，主要纳入创新程度高、临床价值大但超出"保基本"定位的药品，引导商业健康保险纳入保障范围
  • 长期护理保险：覆盖全国1.8亿人，260余万失能参保人享受待遇，加快建立独立险种、全民覆盖的制度体系

11.3 国家医保局支持商业健康保险（2024年10月）
