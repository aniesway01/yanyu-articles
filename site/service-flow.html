战略定位与商业规划

岩育健康 — 公司定位、商业模式与扩展策略

本文件聚焦公司定位、商业模式与扩展策略。具体服务执行流程见《服务执行 SOP》。

一、公司定位

保险理赔咨询顾问 + 长期健康管理代办

角色说明
理赔咨询顾问协助客户最大化理赔成功率，消除医疗保险理赔的不确定性，让客户享受本属于他们的各类保险权益
健康管理代办鼓励客户在每次报销前将资料先提交给我们把关，形成信任关系，成为客户的健康管理伙伴
福利管家（延伸）帮客户扫描保单内所有保障权益（药品商城、洁牙、癌筛、陪诊等），主动提醒使用
  • 我们是保险理赔咨询公司，不是法律公司、不是保险公司。
  • 核心价值：帮保户拿到他本该拿到的钱。
  • 服务边界：以咨询为主，核心工作是「预审 + 审查单位沟通 + 材料优化」。部分保司不允许第三方代办提交，因此我们像律师帮当事人准备材料一样，帮客户整理、优化提交内容。如果保司允许代办，我们也不回避。

二、客户来源与渠道策略

渠道说明
医生转介医生直接告知患者可咨询我们
院内二维码医院放置企业微信二维码，患者自行扫码
药厂销售群当地执行专员拉群，对接有理赔需求的患者
主动触达保单到期前主动联系老客户

渠道发展路径：

  1. 起步阶段（当前）：合作药厂的 HER2 低表达乳腺癌药物已进入 8 个惠民保报销清单，先开放烟台 + 海南 2 个地区
  2. 验证阶段：跑通药厂入口后，逐步扩展到其他地区
  3. 拓展阶段：转向直接与医生合作，扩展到所有商保理赔

三、商业模式

  • 我们帮客户了解保单权益，让他们知道哪些药品在报销范围内
  • 客户知道可以报销后，更愿意选择使用惠民保覆盖的药品（包括合作药厂的产品）
  • 客户实际申请理赔 = 证明我们的服务促成了药品的使用
  • 对客户免费，收入来自药厂渠道服务费

四、初期策略与约束

  • 初期预计日咨询量 ≤10 单
  • 非乳腺癌客户也接，当作累积经验
  • 不急于培训药厂专员：先看实际需求，有问题再沟通
  • 材料收集宁多勿少：完整病历比单独确诊书有用得多
  • 惠民保客户特征：大部分是「裸奔」状态（无其他商保），允许既往症参保，商保渗透率约 5%

五、团队与扩编规划

  • 少辰为核心执行人，负责所有客户对接与理赔咨询
  • 其他人员（何总、Echo 等）为咨询与助力角色
  • 初期不扩编，通过实际运行验证流程后再考虑

六、框架演进机制

本框架不追求一次设计完美，而是通过场景覆盖逐步完善：

  • 前 10 个客户：每个个案都密集复盘，逐步细化服务流程
  • 先跑通再扩展：烟台 + 海南 → 验证后再开放其他地区
  • 重点不是验证成功与否，而是确保遇到的每种客户场景都有对应预案
  • 新场景的记录与归纳方式见附录「场景库」

服务执行 SOP

岩育健康 — 日常服务操作手册

本文件是日常服务的操作手册。公司定位、商业模式与扩展策略见上方《战略定位与商业规划》。不含特定保险产品条款，具体产品服务细则另行建立。

如何使用本文件

本 SOP 有三个核心参考工具，适用于不同场景：

工具位置用途何时查
客户分类表§一判断客户是谁、处于什么状态首次接触时 — 确定客户类型和当前场景
6 阶段流程§二我们该做什么、按什么顺序做每次服务推进时 — 确认当前在哪一步、下一步做什么
服务矩阵§三这次见面具体说什么每次与客户互动前 — 根据类型 × 第几次见面，查对应动作

三者的关系：

  • 分类表回答「客户是谁」→ 流程回答「做什么」→ 矩阵回答「这次见面怎么做」
  • 分类表是静态快照（首次判定 + 阶段升级时更新），流程是动态推进线，矩阵是每次互动的速查卡
  • 实际操作：先查分类表定位 → 沿流程推进 → 每次互动前查矩阵确认重点

一、客户分类

用一张表判断客户状态和对应服务重点。纵轴是客户的就诊阶段（首次接触时判断），横轴是他在理赔流程中的位置（随时间推移会变化）。

理赔前（未提交） 理赔中（已提交） 理赔后
Type 1 未确诊，纯询问 科普 + 保障评估 —（通常不会出现） —
Type 2 已就医未确诊 就医指导 + 提前规划材料 —（通常不会出现） —
Type 3 确诊且用药中 ①用药选择咨询 ②方案已定，预审材料 ③等审核结果 ④被要求补材料 ⑤成功（单次/长疗程） ⑥被拒 → 申诉
Type 4 确诊但被拒赔 — — 拒赔分析 + 申诉指导 + 救济渠道
  • Type 1/2 大多停留在「理赔前」，确诊后自然升级为 Type 3
  • Type 3 是核心服务对象，会经历理赔前→中→后的完整流程
  • Type 4 直接从「理赔后」切入
  • 场景编号①~⑥用于内部记录，不对客户展示
  • 未投保客户：不在表内。告知相关保险信息（去哪里购买、能提供什么保障），引导其投保后再回来找我们

1.2 客户演变路径

首次接触（Type 1~4） ↓ 中间状态 ├─ 单次报销成功 → 推荐续保 / 增值权益 ├─ 单次报销失败 → 二轮申诉服务 ├─ 长疗程首次成功 → 持续跟进理赔 ├─ 长疗程首次失败 → 调整方案再申请 └─ 加购惠民保 + 使用增值服务 ↓ 长期结果 ├─ 深度托付型：主动提交资料，健康管理全托付 ← 理想状态 ├─ 单次型：仅单次报销相关 └─ 流失型：未转化

二、服务全流程（6 阶段）

阶段 1：首次接触（当天）

目标：建立信任 + 收集基本信息

1

开场白

"XXX 您好，这里是岩育健康，我们提供保险理赔的咨询服务，不收取任何费用。这一轮对话主要了解您的基本情况，评估完后会在两个工作天内进一步联系您。请问您目前遇到什么问题？"
2

拉企业微信群

客户 + 岩育专员组成服务群组。

3

告知保密与服务范畴

  • 我们是理赔咨询，不是法律咨询（详见公司定位）
  • 资料仅用于理赔相关用途
  • 说明我们能做什么、不能做什么
4

信息收集清单

项目具体内容
当事人确认是保户本人还是家属代办？
就医状态未就医 / 未确诊 / 已确诊（哪家医院？）
保险状态未投保 / 已投保未申请 / 已投保被拒赔
保险详情哪家公司？什么产品？投保时间？
保险合同PDF 或照片
病历资料尽量完整：住院病历 > 门诊病历 > 确诊书（不止确诊书）
医生原话请客户转达医生对病情的描述
5

告知后续流程

"我们会在两个工作天内反馈评估结果。"

6

初步建议

务必在指定类型医院就诊（通常为二级及以上公立医院普通部）。

注意：不要做成问答模式（参见话术原则「引导而非问答」）。即使客户只是咨询，也要引导他提交资料，并告知"整个过程我们都可以协助跟进"。

阶段 2：内部研究与评估（D+0 ～ D+2）

目标：首次接触后 2 天内完成评估，形成理赔方案

  1. 研究保险合同
    • 找出支持/不支持理赔的条款
    • 确认免赔额、赔付比例、健康体 vs 既往症分级
    • 确认客户投保的是哪个款别
  2. 评估客户状态
    • 所属客户类型 + 当前场景
    • 判断理赔成功率
    • 评估合理理赔金额与可报销项目
  3. 与审查单位沟通（需要时）
    • 疑难 case 提前与审查单位（惠民保为 TPA，非惠民保为保司审查机构）做事前沟通（详见后台流程）
    • 确认适应症与可报销药物的匹配
    • 审查单位反馈时间：最多 2 天，即 D+2 前须收到（与我方研究并行）
    • 此沟通贯穿阶段 2～阶段 4，不是单次动作：评估时问方向，执行时确认细节
    • 审查单位未在 D+2 前回复时：先将已掌握的评估结果反馈客户，注明「审查单位确认中，后续补充」
承诺客户 D+2 内反馈（首次接触当天为 D+0），因此与审查单位的沟通和内部研究必须同步进行，不能串行。

阶段 3：反馈客户（D+2 内）

目标：提供专业建议 + 锁定长期服务关系

  1. 告知理赔评估结果
    • 可申请理赔的项目
    • 预估理赔金额
    • 就医需注意的事项（医院资质、异地备案等）
    • 如客户同时有其他商业保险 → 一并扫描，做全保障评估
  2. 预期管理（参见话术原则）
    • 只说「可能性较高/较低」，不说「一定能赔/不能赔」
    • 最终以审查单位的核定结果为准，我们的评估是帮客户降低对结果的不确定感
    • 站在保户角度尽量争取，但争取不到的如实告知 — 跟律师不保证胜诉一样
  3. 植入长期服务钩子（关键 — 详见阶段 6 粘性逻辑）
    • "下次报销前可以先把材料发给我们，我们帮您预审一遍。"
    • "有新的治疗方案前，可以先跟我们确认哪些药品在报销范围内。"
    • 让客户形成"每次理赔前先找我们"的习惯
  4. 超预期服务（控制客户预期）
    • 本次反馈聚焦客户问的核心问题
    • 后续跟进时再主动告知"我们还研究了您的其他权益"→ 客户没预期到能得到这些服务，对我们印象加深

阶段 4：理赔执行支持

目标：确保材料一次通过

  1. 理赔材料预审
    • 定制个人专属材料清单
    • 客户上传前代为检查：凭证清晰、单据完整、适应症匹配
    • 如有二次报销，提醒保留分割单原件
  2. 特殊情况处理
    • 材料遗失：病历可补，发票可电子化
    • 既往症隐瞒风险：提前告知客户如实提供
    • 指定适应症：确认客户提供了正确的病历
  3. 与审查单位确认提交细节（延续阶段 2 的沟通）
    就具体材料与审查单位确认 ├─ 确认通过 → 指导客户提交 ├─ 有异议 → 补材料 / 请医生出具情况说明 └─ 不回复 → 视情况推进
  4. 提交指导或代办
    • 操作教学：线上提交流程（公众号步骤）、特药直付/直赔申请、一站式结算
    • 默认由客户自己提交，我们提供全程指导
    • 如审查单位允许且客户有需要，可代办提交

阶段 5：理赔后跟踪

目标：闭环 + 处理纠纷

  1. 进度追踪

    《保险法》第 23 条规定保险人须在 30 日内作出核定；各产品实际时限：

    产品常规核定复杂案件拒赔通知备注
    惠琼保10 日内30 日内核定后 3 日内补充材料期间不计入
    烟台市民健康保未明确未明确—以一站式结算/免申直赔为主，条款未载明核定时限

    主动向客户反馈进度。

  2. 结果解读
    • 拆解理算过程（免赔额扣除、比例核算、既往症降幅）
    • 很多客户觉得"赔少了"，需要专业解释
  3. 拒赔申诉
    • 拒赔通知书解读
    • 判定审查单位是否存在核算错误或条例误读
    • 补充材料重新申诉 / 向消保部门投诉
    • 如果我们的能力范围内实在无法满足客户预期 → 转介律所进行诉讼/仲裁（我们不做法律代理，参见公司定位）
  4. 医生协作（需要时）
    • 请医生补开/修改情况说明
    • A 医院或 B 医院开具均可

阶段 6：长期维护与粘性

目标：让客户持续依赖我们，而非一次性服务后脱落

粘性核心逻辑：

  • 不做纯问答 → 每次互动都引导客户把资料交给我们（参见话术原则「引导而非问答」）
  • 不等客户找我们 → 主动定期随访（尤其确诊后第一年复查频率高）
  • 不只做理赔 → 福利管家角色，帮客户用好保单内所有权益
  • 如果客户活跃度下降 → 推送他关心的话题、随访治疗进展、提醒复查

关键粘性动作：

时机动作
理赔成功后梳理保单内其他权益，主动推送
理赔失败后分析原因 + 制定申诉方案，不让客户因失败而脱落
保单到期前续保提醒 + 推荐复发险或增值产品
治疗稳定时通过理赔账单识别治疗阶段 → 推荐复发险
日常推送同病种理赔案例、政策变动预警、健康权益提醒

健康权益管理（福利管家）：

  • 帮客户梳理保单内所有可用权益
  • 主动提醒使用（药品商城、洁牙、癌筛、陪诊、线上问诊等）
  • 推送健康注意事项

增值转化窗口：

  • 窗口 ①：惠民保保障到期时 → 推荐续保或复发险
  • 窗口 ②：标准治疗完成、病情稳定时 → 推荐复发险
  • 如客户同时有其他商保 → 做全保障扫描

三、服务矩阵（客户类型 × 接待次数）

第 1 次见面 第 2 次见面 第 N 次见面
Type 1 白纸 科普 + 收集基本信息 反馈权益评估、告知保单范围、就医注意事项 保单到期提醒 + 续保引导；推送健康权益
Type 2 已就医未确诊 保障评估 + 就医指导 跟进就医进展、提前规划材料方向 持续关注病情；确诊后升级为 Type 3
Type 3 确诊+用药 药物匹配 + 材料准备 反馈审查单位沟通结果、预审后指导提交 追踪理赔进度；疗程变更时重新评估；推荐续保/复发险
Type 4 被拒赔 拒赔分析 + 情绪安抚 反馈申诉方案：补充材料、申诉路径 跟踪申诉进度；推送同病种成功案例
核心逻辑：第 1 次建立信任、收集信息 → 第 2 次反馈专业评估（体现价值）→ 第 N 次持续跟踪 + 主动推送（建立长期依赖）。对应6 阶段流程中的阶段 1 → 阶段 3 → 阶段 6。

四、话术原则

核心：每次互动都争取有效 — 引导客户提交资料，锁定下次联系。

原则说明
引导而非问答尽量引导客户提交资料让我们评估；客户只是随便问 → 轻量回答后告知「没有资料的话不好评估实际情况」，留下下次深入的入口
统问统答收集所有问题和材料 → 约定时间统一回覆，避免碎片化沟通（详见服务模式）
锁定下次每次服务结束都告知"下次理赔/换方案前先联系我们"（对应阶段 3 服务钩子）
预期管理只说可能性高低，强调"审查结果有不确定性，交给我们预审可以降低风险"。争取不到的如实告知
超预期服务后续跟进时主动推出客户没问到的权益信息（对应阶段 3 超预期）
情绪管理有些客户需要安抚，通过事先告知流程和回覆时间缓解焦虑
问题边界乳腺癌以外的理赔/健康问题 → 能力范围内尽量回答（增加信任），超出范畴说明后研究
隐私合规涉及病历等敏感资料，告知客户资料仅用于理赔相关用途

五、服务模式

  • 以企业微信群为主要服务载体（客户 + 岩育专员）。
  • 采用统问统答模式（工单式），不追求即问即答：
    1. 开场说明服务范畴
    2. 请客户一次性提出所有问题并提交资料
    3. 告知回覆时间（D+2 内反馈评估结果）
    4. 整理后统一回覆
  • 理赔咨询不向客户收费（参见商业模式）。
  • 紧急 case：如客户面临用药决策等时间敏感情况，尽量加快速度。但如果实在来不及，让客户先自行决定治疗 — 命比钱重要。

六、后台运行流程

客户提交资料 ↓ ┌ 我方初步评估（研究合同 + 匹配药物/适应症） │ ← 并行，控制在 D+2 内 └ 与审查单位沟通确认能否核销 ↓ 给客户答复（能报什么、不能报什么、需补什么）→ 阶段 3 ↓ 客户根据我们意见准备材料 ↓ 我方预审材料（确保完整正确）→ 阶段 4 ↓ 提交材料 ├─ 客户自行提交（默认）← 我们指导操作 └─ 我方代办提交（审查单位允许时） ↓ 审查单位核定（法定上限 30 日；惠琼保常规 10 日/复杂 30 日；烟台未明确） 惠民保 → TPA 审查后通知保司 非惠民保 → 保司自有审查机构直接审查 ├─ 通过 → 理赔成功 → 阶段 6 长期维护 │ ├─ 单次结束 → 进入长期维护 │ └─ 长疗程 → 下次报销时回到「预审材料」 └─ 拒绝 → 阶段 5 拒赔申诉 → 申诉 / 转介律所

与审查单位协作路径：

我方评估 case → 与审查单位预沟通 ├─ 惠民保 → 对接 TPA └─ 非惠民保 → 对接保司审查机构 ↓ ├─ 确认可行 → 推进理赔 ├─ 有异议 → 补材料 / 请医生出具情况说明 └─ 不回复 → 视情况推进
关键定位：我们是客户与审查单位之间的信息枢纽，确保方向和材料正确。惠民保的审查单位是 TPA，非惠民保则是保司自有审查机构。默认客户自行提交，审查单位允许时可代办。详见公司定位 · 服务边界。
