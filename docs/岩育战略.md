# 岩育健康 — 战略定位与商业规划

> 本文件聚焦公司定位、商业模式与扩展策略。
> 具体服务执行流程见《岩育服务流程.md》。

---

## 一、公司定位

**保险理赔咨询顾问 + 长期健康管理代办**

| 角色 | 说明 |
|------|------|
| **理赔咨询顾问** | 协助客户最大化理赔成功率，消除医疗保险理赔的不确定性，让客户享受本属于他们的各类保险权益 |
| **健康管理代办** | 鼓励客户在每次报销前将资料先提交给我们把关，形成信任关系，成为客户的健康管理伙伴 |
| **福利管家**（延伸） | 帮客户扫描保单内所有保障权益（药品商城、洁牙、癌筛、陪诊等），主动提醒使用 |

- 我们是保险理赔咨询公司，**不是法律公司、不是保险公司**。
- 核心价值：帮保户拿到他本该拿到的钱。
- 服务边界：以咨询为主，核心工作是**「预审 + 审查单位沟通 + 材料优化」**。部分保司不允许第三方代办提交，因此我们像律师帮当事人准备材料一样，帮客户整理、优化提交内容。如果保司允许代办，我们也不回避。

## 二、客户来源与渠道策略

| 渠道 | 说明 |
|------|------|
| 医生转介 | 医生直接告知患者可咨询我们 |
| 院内二维码 | 医院放置企业微信二维码，患者自行扫码 |
| 药厂销售群 | 当地执行专员拉群，对接有理赔需求的患者 |
| 主动触达 | 保单到期前主动联系老客户 |

**渠道发展路径：**
1. **起步阶段**（当前）：合作药厂的 HER2 低表达乳腺癌药物已进入 8 个惠民保报销清单，先开放烟台 + 海南 2 个地区
2. **验证阶段**：跑通药厂入口后，逐步扩展到其他地区
3. **拓展阶段**：转向直接与医生合作，扩展到所有商保理赔

## 三、商业模式

- 我们帮客户了解保单权益，让他们知道哪些药品在报销范围内
- 客户知道可以报销后，更愿意选择使用惠民保覆盖的药品（包括合作药厂的产品）
- 客户实际申请理赔 = 证明我们的服务促成了药品的使用
- **对客户免费，收入来自药厂渠道服务费**

---

## 四、初期策略与约束

- 初期预计日咨询量 ≤10 单
- 非乳腺癌客户也接，当作累积经验
- 不急于培训药厂专员：先看实际需求，有问题再沟通
- 材料收集宁多勿少：完整病历比单独确诊书有用得多
- 惠民保客户特征：大部分是「裸奔」状态（无其他商保），允许既往症参保，商保渗透率约 5%

## 五、团队与扩编规划

- **少辰**为核心执行人，负责所有客户对接与理赔咨询
- 其他人员（何总、Echo 等）为咨询与助力角色
- 初期不扩编，通过实际运行验证流程后再考虑

---

## 六、框架演进机制

本框架不追求一次设计完美，而是通过**场景覆盖**逐步完善：

- 前 10 个客户：每个个案都密集复盘，逐步细化服务流程
- 先跑通再扩展：烟台 + 海南 → 验证后再开放其他地区
- 重点不是验证成功与否，而是确保遇到的每种客户场景都有对应预案
- 新场景的记录与归纳方式见《岩育服务流程.md》附录「场景库」
