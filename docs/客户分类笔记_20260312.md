# 客户分类笔记 — 2026-03-12

## 一、从客户就诊阶段出发的分类

| 类型 | 客户状态 | 核心需求 |
|------|----------|----------|
| **Type 1** | 一片白纸，未确诊，纯询问 | 科普、了解保险能做什么 |
| **Type 2** | 看过医生但未确诊，想知道保单能起什么作用 | 保障评估、就医注意事项 |
| **Type 3** | 看过医生且确诊，有用药，想知道药物能不能报销、保单对疗程有什么好处 | 药物匹配、理赔申请、特药直付 |
| **Type 4** | 看过医生且确诊，已被拒赔 | 拒赔分析、申诉指导、救济渠道 |

## 二、从接待角度出发的分类

这是另一个维度。不管客户属于 Type 1~4 哪种，从我们的角度看只有：

- **第 1 次见面** — 初次接触
- **第 2 次见面** — 回访/跟进
- **第 N 次见面** — 长期客户

## 三、两个维度的关系

这两个分类不是互斥的，是交叉的：

|  | 第 1 次见面 | 第 2 次见面 | 第 N 次见面 |
|--|------------|------------|------------|
| **Type 1** 白纸 | 科普 + 收集基本信息 | 反馈权益评估、告知保单范围、就医注意事项；引导投保（若未投保） | 保单到期提醒 + 续保引导；定期推送健康权益（洁牙、癌筛等） |
| **Type 2** 已就医未确诊 | 保障评估 + 就医指导 | 跟进就医进展：确诊了吗？诊断书内容是否符合要求？提前规划材料方向 | 持续关注病情；确诊后升级为 Type 3；推送相关权益 |
| **Type 3** 确诊+用药 | 药物匹配 + 材料准备 | 反馈 TPA 沟通结果：哪些能报、需补什么材料；预审后指导客户提交保司 | 追踪理赔进度 + 结果解读；疗程变更时重新评估；到期推荐续保/复发险 |
| **Type 4** 被拒赔 | 拒赔分析 + 情绪安抚 | 反馈申诉方案：补充材料清单、医生情况说明、申诉路径 | 跟踪申诉进度；推送同病种成功案例；政策变动主动通知 |

> 核心逻辑：第 1 次建立信任收集信息；第 2 次反馈专业评估（体现价值）；第 N 次持续跟踪+主动推送（建立长期依赖）。

## 四、后台运行流程（接待客户之后）

```
客户提交资料给我们
       │
       ▼
我们跟 TPA（第三方管理机构）沟通
  → 确认能不能核销
       │
       ▼
给客户答复
  → 告知哪些能报、哪些不能、需要补什么
       │
       ▼
客户根据我们的意见准备/整理申请材料
       │
       ▼
客户提交材料给保司
       │
       ▼
等保司审核结果
  ├─ 通过 → 理赔成功
  └─ 拒绝 → 回到我们，进入申诉流程
```

> 关键点：我们不是直接帮客户提交给保司，而是在中间做「预审 + TPA 沟通」的角色，确保客户提交的材料和方向是对的。
