# 岩育健康 — 服务流程

## 一、公司定位

**保险理赔咨询顾问 + 长期健康管理代办**

1. **理赔咨询顾问**：协助客户最大化理赔成功率，消除医疗保险理赔的不确定性，让客户享受本属于他们的各类保险权益。

2. **健康管理代办**：保险条款对客户来说是较大的心智负担，我们鼓励客户在每次报销前将资料先提交给我们把关，形成客户愿意主动提交医疗相关资料的信任关系，成为客户的健康管理伙伴。

## 二、服务模式

以**微信群**为主要服务载体，通过微信消息解决客户疑惑。

## 三、客户分类（按就诊阶段）

| 类型 | 客户状态 | 核心需求 |
|------|----------|----------|
| **Type 1** | 一片白纸，未确诊，纯询问 | 科普、了解保险能做什么 |
| **Type 2** | 看过医生但未确诊，想了解保单作用 | 保障评估、就医注意事项 |
| **Type 3** | 确诊且用药中，想知道能不能报销 | 药物匹配、理赔申请、特药直付 |
| **Type 4** | 确诊但被拒赔 | 拒赔分析、申诉指导、救济渠道 |

## 四、主要服务流程

### 阶段 1：接触客户，搜集信息

- 通过医生转介 / 院内二维码 / 药厂销售群接触客户
- 在企业微信上拉群
- 搜集：当事人身份、就医状态、保险状态、合同、病历

### 阶段 2：专业评估

- 研究保险合同条款，评估理赔可行性
- 匹配药物与保单覆盖范围
- 复杂个案：与 TPA（第三方管理机构）协商确认能否核销

### 阶段 3：提交理赔建议

- 告知客户哪些能报、哪些不能、需要补什么材料
- 提供专业的材料准备指导

### 阶段 4：协助理赔执行

- 预审客户材料，确保提交前无误
- 引导客户操作线上/线下提交流程
- 特药直付申请协助

### 阶段 5：理赔后跟踪

- 追踪理赔进度，反馈审核结果
- 理赔结果解读（拆解理算过程）
- 拒赔时：分析原因 → 制定申诉方案 → 跟踪申诉进度
- 持续性理赔需求（如慢性处方）：持续提供协助

### 阶段 6：长期维护

- 启动健康管理服务
- 保单到期提醒 + 续保引导
- 推荐复发险等增值产品
- 推送健康权益（洁牙、癌筛等）

## 五、服务矩阵（客户类型 × 接待次数）

|  | 第 1 次见面 | 第 2 次见面 | 第 N 次见面 |
|--|------------|------------|------------|
| **Type 1** 白纸 | 科普 + 收集基本信息 | 反馈权益评估、告知保单范围、就医注意事项 | 保单到期提醒 + 续保引导；推送健康权益 |
| **Type 2** 已就医未确诊 | 保障评估 + 就医指导 | 跟进就医进展、提前规划材料方向 | 持续关注病情；确诊后升级为 Type 3 |
| **Type 3** 确诊+用药 | 药物匹配 + 材料准备 | 反馈 TPA 沟通结果、预审后指导提交 | 追踪理赔进度；疗程变更时重新评估；推荐续保/复发险 |
| **Type 4** 被拒赔 | 拒赔分析 + 情绪安抚 | 反馈申诉方案：补充材料、申诉路径 | 跟踪申诉进度；推送同病种成功案例 |

## 六、后台运行流程

```
客户提交资料
    ↓
我们与 TPA 沟通确认能否核销
    ↓
给客户答复（能报什么、不能报什么、需补什么）
    ↓
客户根据我们意见准备材料
    ↓
客户提交材料给保司
    ↓
保司审核
  ├─ 通过 → 理赔成功
  └─ 拒绝 → 回到我们，进入申诉流程
```

> 关键：我们不代替客户提交，而是做「预审 + TPA 沟通」，确保方向和材料正确。
