## 一、结论先行

**白血病的治疗费用（含院外药品）原则上是可以报销的**——但能不能赔到钱，**关键不在病种，而在 4 件事**：

1. **投保前是否已确诊**？已确诊的踩既往症条款，**全额拒赔**
2. **是否在等待期内接受过相关检查**？即便等待期后才确诊也拒赔
3. **白血病亚型/分期**？**Binet A 期 CLL** 是唯一被排除的分期，不能走重疾，但可走一般医疗的兜底
4. **院外药品是否走了授权审核流程**？自购、买未上市药、在非指定药店买的，全部不报

**先索取材料、核对时间线，再答复客户** —— 见第六节。

## 二、支持理赔的条款依据（PRO）

### PRO-1：白血病归属"恶性肿瘤——重度"，是合同列明的重大疾病

**【解读】**

白血病在 ICD-10 中归类为 C91-C95（淋巴/造血及相关组织恶性肿瘤），ICD-O-3 形态学编码 9800-9948 属于 /3 行为性质码（恶性、原发部位），**完全落入合同"恶性肿瘤——重度"的定义**。条款特别提到「涵盖**骨髓**病理学检查」——明显是为白血病这类血液恶性肿瘤量身写的兜底。

**结论**：白血病 = 重大疾病，能走重疾医疗保险金（见 PRO-3）。**例外见 CON-3**。

**【原文依据】**

> （一）恶性肿瘤——重度指恶性细胞不受控制的进行性增长和扩散，浸润和破坏周围正常组织，可以经血管、淋巴管和体腔扩散转移到身体其他部位，病灶经组织病理学检查（释义四十六）（涵盖骨髓病理学检查）结果明确诊断，临床诊断属于世界卫生组织（WHO，World Health Organization）《疾病和有关健康问题的国际统计分类》第十次修订版（ICD-10） （释义四十七）的恶性肿瘤类别及《国际疾病分类肿瘤学专辑》第三版（ICD-O-3） （释义四十七）的肿瘤形态学编码属于3、6、9（恶性肿瘤）范畴的疾病。

### PRO-2：重大疾病医疗保险金覆盖白血病的住院 + 化疗 + 靶向 + 免疫治疗

**【解读】**

这是白血病案例的**主报销路径**。覆盖范围非常宽：

- **住院医疗费用**——床位、护理、ICU、检查、药品、手术、救护车等**所有住院相关费用**
- **重大疾病特殊门诊费用**——明确包含**门诊化疗、放疗、免疫疗法、内分泌疗法、靶向疗法**（这正是白血病的核心治疗手段）
- **门诊手术 + 住院前后 7 天 / 30 天的门急诊**

跟"一般医疗保险金"的区别：
- 必须是合同认定的**重大疾病**——白血病符合（除 Binet A CLL）
- 必须**初次确诊**（释义二十四）—— 投保前已诊断的，**直接拒赔**（见 CON-1）

**【原文依据】**

> （二）重大疾病医疗保险金（必选）在保险期间内，被保险人因遭受意外伤害事故或在等待期后经医院初次确诊（释义二十四）罹患本合同约定的重大疾病，并在医院接受治疗的，保险人对下述1-4类费用，按照本合同的约定承担给付重大疾病医疗保险金的责任：
> 1.重大疾病住院医疗费用指被保险人经医院诊断罹患重大疾病必须接受住院治疗时，被保险人住院期间发生的需个人支付的、必需且合理的重大疾病住院医疗费用，包括床位费、加床费、膳食费、护理费、重症监护室床位费、诊疗费、检查检验费、治疗费、药品费、手术费、救护车使用费等。到本合同满期日时，被保险人未结束本次住院治疗的，保险人继续承担因本次住院发生的、最高不超过本合同满期日后30 日内的住院医疗费用。
> 2.重大疾病特殊门诊医疗费用指被保险人经医院诊断必须接受重大疾病特殊门诊治疗时，被保险人需个人支付的、必需且合理的重大疾病特殊门诊医疗费用，包括：
> （1）门诊肾透析费；
> （2）门诊恶性肿瘤——重度治疗费，包括化学疗法、放射疗法、肿瘤免疫疗法、肿瘤内分泌疗法、肿瘤靶向疗法的治疗费用；
> （3）器官移植后的门诊抗排异治疗费。
> 3.重大疾病门诊手术医疗费用指被保险人经医院诊断罹患重大疾病必须接受门诊手术治疗时，被保险人需个人支付的、必需且合理的重大疾病门诊手术医疗费用。
> 4.重大疾病住院前后门急诊医疗费用指被保险人经医院诊断罹患重大疾病必须接受住院治疗，在住院前7日（含住院当日）和出院后30日（含出院当日）内，因与该次住院相同原因而接受重大疾病门急诊治疗时，被保险人需个人支付的、必需且合理的重大疾病门急诊医疗费用（但不包括重大疾病特殊门诊医疗费用和重大疾病门诊手术医疗费用）。对于以上四类费用，保险人对于被保险人需个人支付的、必需且合理的金额，依照约定的给付比例进行赔付。保险人在本项下累计给付金额以本合同约定的重大疾病医疗保险金额为限，当保险人在本项下的累计给付金额达到本项保险金额时，保险人对被保险人在本项下的保险责任终止。

### PRO-3：Binet A 期 CLL 虽然被重疾排除，但仍有兜底——一般医疗的特殊门诊

**【解读】**

合同设计了一个**精巧的兜底机制**：在"一般医疗保险金"的"特殊门诊医疗费用"分项里，特别列出一条**不属于"恶性肿瘤——重度"的恶性肿瘤门诊治疗费**也能报销，明确包括化学疗法、放射疗法、肿瘤免疫疗法、肿瘤内分泌疗法、肿瘤靶向疗法。

这正是为 **Binet A 期 CLL** 这种被排除项排掉的"轻度恶性肿瘤"准备的——虽然不能走重疾医疗，**仍可走一般医疗的门诊化疗/靶向治疗费**。注意：一般医疗保险金有免赔额（一般 1 万元，具体看保单页），重疾医疗保险金通常无免赔额。

**【原文依据】**

> 2.特殊门诊医疗费用指被保险人经医院诊断必须进行特殊门诊治疗时，被保险人需个人支付的、必需且合理的特殊门诊医疗费用，包括：
> （1）门诊肾透析费；
> （2）不属于本合同约定的“ 恶性肿瘤——重度 ”（释义五.一）的恶性肿瘤门诊治疗费，包括化学疗法（释义十八）、放射疗法（释义十九）、肿瘤免疫疗法（释义二十）、肿瘤内分泌疗法（释义二十一）、肿瘤靶向疗法（释义二十二）的治疗费用；

### PRO-4：院外购药明确允许，但必须走授权流程

**【解读】**

这是客户原话「患者说是院外的也可以报销的」对应的条款。条款**确实允许**院外购药报销，挂在 **一般医疗 / 重疾医疗 / 指定疾病特需** 三档保险责任下（**质子重离子和重疾津贴不适用**）。

但**触发条件 + 流程**很严格，必须三件事都做对：

1. **触发条件**：必须是「专科医生开具的当前治疗必需的药品处方中所列药品**若无法在本次住院医院内获得**」——隐含要求**先有住院**，门诊单独购药能否走需进一步与众安客服确认（实务纠纷点）
2. **三步流程**：授权申请 → 药品处方审核 → 在保险人**指定/认可的药店**购药
3. **药品资质**：必须是合同期满日前**在中国国家药品监督管理局批准且已在中国大陆（不包括港澳台）上市**的；每次处方剂量**不超过 30 天**

**违反任何一条都会被拒赔，详见 CON-3**。

**【原文依据】**

> 以上“（一）一般医疗保险金”、“（二）重大疾病医疗保险金”和“（五）指定疾病及手术特需医疗保险金”保险责任，由专科医生开具的当前治疗必需的药品处方中所列药品若无法在本次住院医院内获得，被保险人可从院外购买药品，保险人分别在各项责任保险金额下赔付。但被保险人需按照保险人指定的以下流程进行授权申请、药品处方审核和药品购买：
> （1）授权申请被保险人或受益人作为申请人向保险人提交院外药品购买授权申请（以下简称“授权申请”），并按照保险人的要求提交相应授权申请材料，包括但不限于与被保险人相关的个人信息、诊断证明、与诊断证明相关的检查检验报告、药品处方及其他所需要的医学材料。
> （2）药品处方审核保险人或保险人指定机构对被保险人进行药品处方审核。若申请人的药品处方审核未通过，保险人不承担给付相应保险金的责任。保险人或保险人指定机构对被保险人进行药品处方审核的标准和依据：a.药品处方真实性审核；b.处方用药是否医学必需且合理。对是否为治疗必需的药品由保险人根据客观、审慎、合理的原则进行审核；如果被保险人对审核结果有不同意见，可由双方认同的权威医学机构或者权威医学专家进行审核鉴定。每次院外药品的处方剂量不得超过30 天，且药品需为本合同期满日前在中国国家药品监督管理局批准且已在中国（不包括港澳台地区）上市的。
> （3）药品购买药品处方审核通过后，保险人将会提供购药凭证，被保险人可根据保险人指引，携带其有效身份证件、社会保障卡、有效药品处方和购药凭证在保险人指定的药店（释义三十）自取药物，并按照相应保险条款在店内进行理赔实时结算。如果被保险人自行在保险人认可的药店（释义三十一）购药，可事后凭发票及相关材料，向保险人提出理赔申请。在保险期间内，若保险人上述（一）至（五）项责任下的累计给付保险金的总额达到本合同载明的总保险金额时，本合同终止。

## 三、可能造成不理赔的风险条款（CON）

### CON-1：既往症 / 等待期内确诊（**最大风险，最常导致拒赔**）

**【解读】**

这是本案例**最大的不确定因素**。条款把三种情形列为"既往疾病"免责：

1. **先天性疾病**（按 ICD-10 确定）——白血病一般不归类先天疾病，但**先天性血液病**（如范可尼贫血、Diamond-Blackfan 贫血）转化白血病可能踩这条
2. **被保险人所患既往症**——投保前**已诊断**或**已有相关症状/检查异常但未确诊**的，相关费用全部不赔
3. **等待期内接受检查但在等待期后确诊的同一种疾病**——这是最阴险的一条，即使确诊日在等待期之后，但只要"等待期内做过相关检查"（哪怕只是血常规、骨穿、超声），同一疾病的费用都不赔

**等待期通常 30 天**（具体看保单页）。

**必须做的核对**：
- 投保日期 → 等待期截止日期
- 患者**首次出现症状**的日期（贫血、出血、淋巴结肿大、骨痛等）
- 患者**首次就诊**的日期 + 当时做过哪些检查
- 患者**首次确诊白血病**的日期

只要其中任何一个早于"等待期截止日"，就有拒赔风险。

**【原文依据】**

> （一）既往疾病：先天性疾病（依据世界卫生组织《疾病和有关健康问题的国际统计分类》（ICD-10）确定）；被保险人所患既往症（释义三十三）及保险单中特别约定的除外疾病引起的相关费用；等待期内接受检查但在等待期后确诊的同一种疾病；

### CON-2：Binet A 期慢性淋巴细胞白血病不算重疾

**【解读】**

合同把 **Binet A 期 CLL** 列为"恶性肿瘤——重度"的排除项第 5 项。CLL 最早期通常临床上视作观察期，不立即治疗（"watch and wait"）。

**对客户案例的影响**：

| 患者亚型 | 走哪档？ | 备注 |
|---|---|---|
| **AML**（急性髓系） | ✅ 重疾医疗（PRO-2） | 主路径，无问题 |
| **ALL**（急性淋巴） | ✅ 重疾医疗（PRO-2） | 同上 |
| **CML**（慢性髓系） | ✅ 重疾医疗（PRO-2） | 同上 |
| **CLL Binet B 期** | ✅ 重疾医疗（PRO-2） | 同上 |
| **CLL Binet C 期** | ✅ 重疾医疗（PRO-2） | 同上 |
| **CLL Binet A 期** | ⚠️ **走一般医疗 PRO-3 兜底** | 不能走重疾，但门诊化疗/靶向仍可报 |
| **儿童白血病** | ✅ 重疾医疗 | 全部覆盖 |
| **MDS 转化白血病** | ✅ 重疾医疗 | 一旦转化按白血病计 |

**所以这个排除项的影响其实有限**——只对成人 Binet A 期 CLL 这一窄分期生效，且仍有 PRO-3 兜底。

**【原文依据】**

> 下列疾病不属于本合同约定的“恶性肿瘤——重度”，不在保障范围内：
> 1.ICD-O-3肿瘤形态学编码属于0（良性肿瘤）、1（动态未定性肿瘤）、2（原位癌和非侵袭性癌）范畴的疾病，如：a.原位癌，癌前病变，非浸润性癌，非侵袭性癌，肿瘤细胞未侵犯基底层，上皮内瘤变，细胞不典型性增生等；b.交界性肿瘤，交界恶性肿瘤，肿瘤低度恶性潜能，潜在低度恶性肿瘤等；
> 2.TNM分期（释义四十八）为Ⅰ期或更轻的甲状腺癌TNM分期；
> 3.TNM分期为T1N0M0期或更轻分期的前列腺癌；
> 4.黑色素瘤以外的未发生淋巴结和远处转移的皮肤恶性肿瘤；
> 5.相当于Binet分期方案A期程度的慢性淋巴细胞白血病；
> 6.相当于Ann Arbor分期方案Ⅰ期程度的何杰金氏病；
> 7.未发生淋巴结和远处转移且WHO分级为G1级别（核分裂像<10/50 HPF和ki-67≤2%）或更轻分级的神经内分泌肿瘤。

### CON-3：院外购药流程违规会被全额拒付

**【解读】**

PRO-4 引用的条款同时是 CON-3——院外购药**只要踩任何一条**，整笔药费全部不赔。常见违规情形：

| 违规类型 | 后果 |
|---|---|
| 客户**自己先买后报销** | 没走授权流程，拒赔 |
| 处方真实性 / 医学必要性**审核未通过** | 条款明文写「保险人不承担给付相应保险金的责任」 |
| 在**保险人未指定 / 未认可的药店**购买 | 不在赔付清单内 |
| 买的是**未在中国大陆 NMPA 上市**的药（港澳代购、印度仿制药、临床试验药、特批药、跨境医疗带回的药） | 不符合药品资质要求 |
| 单次处方**超过 30 天剂量** | 超出部分不赔 |
| 在没有住院的情况下纯门诊购药 | 触发条件 **本次住院医院内无法获得** 未满足，可能被拒（实务纠纷点） |
| 没有提交完整的授权申请材料（漏诊断证明 / 检查报告 / 处方原件） | 审核不通过 |

**对客户的话术**：不要直接说「能报」或「不能报」，先按下一节六的清单**问清问题**。强调一句：**报销前必须先向众安提出院外购药授权申请，得到处方审核通过 + 购药凭证后才能去指定药店买药**。提醒一句：**未上市的进口药、临床试验药、港澳台药品一律不在保障范围内**。

**【原文依据】** 同 PRO-4

## 四、后续医疗行为要注意的事项

为保住理赔资格，**告知客户后续治疗时的 7 个注意事项**：

### 4.1 院外购药 — 一定先申请，再买药

**绝对不要先买后报销**。每次需要购买院外药前：
1. 让主治医生开规范处方（注明诊断、药名、剂量、疗程）
2. 联系众安客服或线上平台（保单上有客服电话）提交**院外购药授权申请**，附上诊断证明、检查检验报告、处方原件、被保险人个人信息
3. 等待**药品处方审核**结果（通常 1-3 个工作日）
4. 审核通过后凭众安提供的**购药凭证**，在**众安指定的药店**自取（实时结算更方便），或在**众安认可的药店**买完凭发票事后申请理赔
5. 注意**单次处方不得超过 30 天剂量**，长期治疗要分次申请

**指定药店名单**通常是众安合作的 DTP 药房（如思派、上药云健康、镁信健康等），需向客服索取**最新名单**——以保险人当前公布为准，不要拿旧名单。

### 4.2 治疗医院的选择 — 必须是合同认定的"医院"

合同对"医院"有定义（释义六），一般指**二级及以上公立医院**。**避免**：
- 私立诊所、社区门诊
- 未取得医疗机构执业许可证的机构
- 非主治科室或非血液科治疗（特殊情况除外）

如果患者**有可能去特需医疗机构、国际部、或港澳合作医院**治疗，要**先确认保单是否投保了"指定疾病及手术特需医疗保险金（可选）"档**——这是可选责任，不投就不能扩展医院范围。

### 4.3 留存所有医疗材料

每次就诊**必须保留**：
- **诊断证明书**（含 ICD 编码、白血病具体亚型、分期）
- **病理报告**（骨穿、活检、流式细胞、染色体、基因等）
- **检查检验报告**（血常规、生化、影像）
- **处方原件**
- **门诊/住院病历首页和出院小结**
- **费用清单 + 发票原件**（注意：基本医保结算后会出"分割单"，**必须保留**）
- **入出院记录**

理赔时**一次性**提交，避免反复补单。

### 4.4 与基本医保 / 大病保险的衔接

好医保适用**医疗费用补偿原则**（合同第九条）——已经从基本医保、大病保险、其他商保获得的报销部分，**好医保只补差额**。

注意：
- **基本医保的"个人账户支付"部分**视为**自费**，可正常报销给好医保
- **基本医保的"统筹账户报销"部分**已经被报销过，**不能在好医保重复报销**
- 如果**没有用基本医保身份就诊**（比如直接自费就医），可能被限制报销比例

**实务建议**：先走基本医保，再走好医保补差。注意保留分割单。

### 4.5 等待期内不要做"白血病相关"的检查

如果保单**还在等待期内**（一般 30 天），**避免**做任何可能暗示白血病的检查（血常规异常、骨穿、流式、淋巴结活检等）。条款规定**等待期内做过检查 + 等待期后确诊同一种病 = 拒赔**。

如果患者**已经有症状**（疑似白血病的发热、贫血、出血、淋巴结肿大），但保单还在等待期，**等待期结束后再就诊**——但这要权衡医疗紧迫性，**生命安全永远优先于报销**。

### 4.6 续保不保证 —— 提前规划 Plan B

好医保是**不保证续保**产品。即使本期保单覆盖了本次治疗，**下一年若病情持续可能被拒保或停售**。客户必须有 **Plan B**：
- 其他正在保的商业重疾险
- 当地惠民保（多数对既往症有专门的轻度保障）
- 公益基金、慈善救助、白血病专项救助
- 储蓄 / 借款 / 众筹

**不要把希望全部押在一份不保证续保的医疗险上**。

### 4.7 治疗方案的选择影响理赔范围

某些**新疗法**目前不在好医保的常规理赔范围内：

- **CAR-T 细胞免疫治疗**——目前国内只有阿基仑赛、瑞基奥仑赛等少数 NMPA 批准的产品。**理赔需逐案审核**，且单价 100 万元起，通常超出本档保额
- **造血干细胞移植**——属于"指定移植手术"，可能落在**指定疾病特需可选档**（若投保了）
- **临床试验阶段的新药**——不报
- **港澳台 / 海外治疗**——不报

主治医生建议方案后，客户**应主动询问众安客服当前方案是否在理赔范围内**，避免治疗后才发现不在保障内。

## 五、必问客户的 6 个问题 + 必索取的 5 项材料

### 必问问题

| # | 问题 | 用途 |
|---|---|---|
| 1 | 患者**白血病的具体亚型 / 分期**？（AML / ALL / CML / CLL，CLL 的 Rai/Binet 分期） | 决定走 PRO-2（重疾医疗）还是 PRO-3（一般医疗兜底） |
| 2 | **首次确诊日期**？医院出具的诊断书或病理报告日期 | 跟保单生效日 + 等待期截止日比对（CON-1） |
| 3 | **首次出现症状 / 首次就诊**的日期？等待期内有没有做过血常规、骨穿、淋巴结活检等检查？ | 排查 CON-1 的"等待期内检查"陷阱 |
| 4 | 这份**好医保保单的生效日期、本次续保起期**？被保险人是不是 Luke 总转的患者本人？ | 不保证续保产品，需确认本年度保单是否在保险期间 |
| 5 | 「**院外购药**」具体指什么药？是 PD-1 抑制剂、酪氨酸激酶抑制剂（伊马替尼/达沙替尼/尼洛替尼）、维奈克拉、CAR-T 等中的哪一类？是否已经在中国 NMPA 上市？ | 院外药品必须是 NMPA 批准的国内上市药；CAR-T 等需逐案确认 |
| 6 | 保单是否投保了**「指定疾病及手术特需医疗保险金」可选责任档**？保单页上能看到。 | 决定患者能否去特需医疗机构 / 国际部 / 港澳合作医院治疗 |

### 必索取材料

1. 患者**身份证 + 投保人 / 被保险人**关系证明
2. **好医保电子保单页**（含起保日期、各档保额、免赔额、是否投了可选责任）
3. **首次就诊和首次确诊的医院诊断书 + 病理报告**（含 ICD 编码、白血病亚型、分期）
4. **当前处方清单 + 治疗方案**（特别是患者所说的"院外药品"具体是哪些 + 主治医生建议的治疗方案）
5. **历次理赔记录**（基本医保、大病保险、其他商保的报销凭证 — 用于补偿原则的扣减计算）

## 六、行动建议

1. **第一步：要材料**——按上面 5 项清单跟 Luke 总要齐
2. **第二步：核对时间线**——投保日 / 等待期截止日 vs 首次症状日 / 首次就诊日 / 首次确诊日，**任何一个早于等待期截止日都有拒赔风险**
3. **第三步：定路径**：
   - 若**已踩既往症 / 等待期陷阱** → 这份好医保**已无法报销**，转告 Plan B（惠民保、其他商保、白血病专项救助）
   - 若**首次确诊在保险期间内 + 等待期后**：
     - 主流亚型（AML/ALL/CML/B/C 期 CLL/儿童白血病）→ 走 **PRO-2 重疾医疗**
     - **Binet A 期 CLL** → 走 **PRO-3 一般医疗的特殊门诊兜底**
     - 投了可选档 → 可扩展到特需医疗机构
4. **第四步：院外购药**——按第四节 4.1 教客户走授权流程，**绝对不要先买后报**
5. **第五步：告知后续注意事项**——把第四节 4.1-4.7 的注意事项打包给客户，避免后续治疗中无意触雷
6. **第六步：续保规划**——告知不保证续保的事实，建议客户**同步评估其他在保的商业险 / 惠民保 / 公益基金**
