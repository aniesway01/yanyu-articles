## 一、结论先行

| 问题 | 答复 | 关键依据 |
|---|---|---|
| 白血病在条款里属于哪一档？ | 一般情况下属于「**恶性肿瘤——重度**」（释义五.一），即「重大疾病」 | 释义五.一 + ICD-10/ICD-O-3 形态学编码 3/6/9 |

## 二、白血病的条款定位（核心问题）

### 2.1 白血病 → 属于「恶性肿瘤——重度」

合同**释义五·重大疾病·（一）恶性肿瘤——重度**（PDF Page 16-17, 合同全文.md L1228-1246）：

> 「指恶性细胞不受控制的进行性增长和扩散，浸润和破坏周围正常组织，可以经血管、淋巴管和体腔扩散转移到身体其他部位，**病灶经组织病理学检查（涵盖骨髓病理学检查）结果明确诊断**，临床诊断属于世界卫生组织（WHO）《疾病和有关健康问题的国际统计分类》第十次修订版（ICD-10）的恶性肿瘤类别及《国际疾病分类肿瘤学专辑》第三版（ICD-O-3）的肿瘤形态学编码属于 **3、6、9（恶性肿瘤）范畴的疾病**。」

**解读**：白血病在 ICD-10 中归类为 C91-C95（淋巴/造血及相关组织恶性肿瘤），ICD-O-3 形态学编码 9800-9948 属于 /3 行为性质码（恶性，原发部位），**完全落入「恶性肿瘤——重度」定义**。条款特别提到「涵盖**骨髓**病理学检查」，明显是为白血病这类血液恶性肿瘤量身写的。

### 2.2 **唯一的排除分期**：Binet A 期慢性淋巴细胞白血病

释义五.一 紧接着列出 7 项不予承认的「轻度恶性肿瘤」（PDF Page 17, 合同全文.md L1249-1287），与白血病相关的是第 5 条：

> 「下列疾病不属于本合同约定的"恶性肿瘤——重度"，不在保障范围内：
> ……
> **5. 相当于 Binet 分期方案 A 期程度的慢性淋巴细胞白血病；**
> 6. 相当于 Ann Arbor 分期方案 Ⅰ 期程度的何杰金氏病；
> ……」

**解读**：
- **Binet A 期 CLL** 是 CLL 最早期（淋巴细胞增多但无贫血/血小板减少、受累区域 ≤2），临床上视同观察期，不立即治疗 → **不能走重疾医疗保险金**。
- 但**仍可走「一般医疗保险金」**，因为「一般医疗保险金」覆盖的是"重大疾病以外的其他疾病"（第六条第一款，PDF Page 6, 合同全文.md L209-215）。
- 急性白血病（AML / ALL）、CML、Binet B/C 期 CLL、所有儿童白血病、各种 MDS 转化白血病等 → **不在排除项**，正常按重大疾病走。

### 2.3 客户案例的下一步追问（必须问到才能给客户答复）

| 必须问 | 为什么 |
|---|---|
| ① 患者**白血病的具体亚型 / 分期**？（AML / ALL / CML / CLL，CLL 的 Rai/Binet 分期） | 决定走「重疾医疗」还是「一般医疗」 |
| ② **首次确诊日期**？医院出具的诊断书或病理报告日期 | 用于和保单生效日比对（既往症？等待期？） |
| ③ 这份**好医保保单的生效日期、本次续保起期**？被保险人是不是 Luke 总转的患者本人？ | 不保证续保产品，需确认本年度保单是否在保险期间 |
| ④ 「**院外购药**」具体指什么药？是 PD-1 抑制剂、酪氨酸激酶抑制剂（伊马替尼/达沙替尼/尼洛替尼）、维奈克拉、CAR-T 等中的哪一类？是否已经在中国 NMPA 上市？ | 院外药品必须为「合同期满日前在中国国家药品监督管理局批准且已在中国（不包括港澳台）上市」的，且要通过保险人处方审核 |
| ⑤ 患者目前**已经在哪个医院、由哪位医生治疗**？是否在「保险人指定的医疗机构 / 指定药店」名单内？ | 质子重离子治疗有指定机构限制；院外购药须在指定/认可药店 |

## 三、可能调用的保险责任档位

合同**第六条 保险责任**（PDF Page 6-9, 合同全文.md L185-580）共 5 档，与白血病相关的：

### 3.1 一般医疗保险金（必选）— 适用于排除项的 Binet A 期 CLL

> 「在保险期间内，被保险人因遭受意外伤害事故或在等待期后因罹患本合同约定的**重大疾病以外的其他疾病**，在医院接受治疗的，保险人对下述 1-4 类费用，按照本合同的约定承担给付一般医疗保险金的责任：
> 1. 住院医疗费用
> 2. 特殊门诊医疗费用（包括 **不属于"恶性肿瘤——重度"的恶性肿瘤门诊治疗费**，含化学疗法、放射疗法、肿瘤免疫疗法、肿瘤内分泌疗法、肿瘤靶向疗法）
> 3. 门诊手术医疗费用
> 4. 住院前后门急诊医疗费用」

**关键发现**：合同**特别在「一般医疗保险金的特殊门诊」里**单独写了一条「不属于'恶性肿瘤——重度'的恶性肿瘤门诊治疗费」，**就是为 Binet A 期 CLL 这种轻度恶性肿瘤兜底的**。所以即使是排除项里的 CLL，门诊化疗 / 靶向 / 免疫疗法依然能报。

### 3.2 重大疾病医疗保险金（必选）— 主战场，适用于绝大多数白血病

> 「在保险期间内，被保险人因遭受意外伤害事故或在等待期后经医院**初次确诊**罹患本合同约定的重大疾病，并在医院接受治疗的，保险人对下述 1-4 类费用……：
> 1. 重大疾病住院医疗费用
> 2. 重大疾病特殊门诊医疗费用（含化疗、放疗、肿瘤免疫疗法、肿瘤内分泌疗法、肿瘤靶向疗法）
> 3. 重大疾病门诊手术医疗费用
> 4. 重大疾病住院前后门急诊医疗费用」

**注意**：第二档要求**「初次确诊」**（释义二十四），即被保险人**在保险期间内首次诊断**。若客户在投保前已确诊白血病，**直接踩中既往症 → 第十条责任免除（一）拒赔**。

### 3.3 质子重离子医疗保险金（必选）— 白血病一般用不上

> 「在保险期间内，被保险人在等待期后经医院初次确诊罹患本合同所定义的恶性肿瘤——重度，并**于保险人指定的医疗机构**接受质子重离子治疗的……」（PDF Page 8, 合同全文.md L396-429）

**解读**：质子重离子是实体瘤（特别是头颈部、脑、前列腺等）的精准放疗，**白血病通常不用质子重离子治疗**（白血病走化疗 + 靶向 + 免疫 + 造血干细胞移植）。这档不是白血病的现实选项。

### 3.4 重大疾病津贴保险金（必选）— 一次性给付

> 「初次确诊罹患本合同所定义的重大疾病中列明的任意一种或者多种疾病，保险人按照本合同的约定向被保险人给付重大疾病津贴保险金，**同时本项保险责任终止**。」（PDF Page 9, 合同全文.md L437-446）

白血病若属于"恶性肿瘤——重度"且符合「初次确诊」条件，可一次性领取津贴。**注意**：领完该项责任就终止，不影响重大疾病医疗保险金的报销。

### 3.5 指定疾病及手术特需医疗保险金（可选）— 看保单是否勾选

> 「将上述（一）一般医疗保险金和（二）重大疾病医疗保险金中的医院范围**扩展至特定医疗机构**（释义二十七），对于被保险人在特定医疗机构所发生的各项医疗费用……：
> 1. **恶性肿瘤——重度**、严重非恶性颅内肿瘤或重型再生障碍性贫血的治疗；
> 2. 指定移植手术（释义二十八）；
> 3. 指定重大手术（释义二十九）。」（PDF Page 9, 合同全文.md L449-485）

**关键**：这是**可选**责任，需要核对患者**这份保单是否投了这一档**。若有，则化疗/造血干细胞移植可以扩展到指定的特需医疗机构（如部分港澳/特需国际部）。

## 四、客户最关心的「院外药品报销」条款

合同**第六条 末段**（PDF Page 9-10, 合同全文.md L497-580）专门规定院外购药。**逐字引用首段触发条件**：

> 「以上"（一）一般医疗保险金"、"（二）重大疾病医疗保险金"和"（五）指定疾病及手术特需医疗保险金"保险责任，由专科医生开具的当前治疗必需的药品处方中所列药品若无法在本次住院医院内获得，被保险人可从院外购买药品，保险人分别在各项责任保险金额下赔付。但被保险人需按照保险人指定的以下流程进行授权申请、药品处方审核和药品购买」

下面 (1)(2)(3) 三步流程**为我精简的概要**（原文每步都有更详细的法律措辞，详见 `合同全文.md` L497-575）：

- **（1）授权申请**：被保险人或受益人作为申请人向保险人提交院外药品购买授权申请，按照保险人要求提交个人信息、诊断证明、与诊断证明相关的检查检验报告、药品处方及其他所需医学材料。
- **（2）药品处方审核**：保险人或其指定机构审核 a. 药品处方真实性；b. 处方用药是否医学必需且合理。**审核未通过，保险人不承担给付相应保险金的责任**。
- **（3）药品购买**：审核通过后，保险人提供购药凭证，被保险人携带有效身份证件、社保卡、有效药品处方和购药凭证，在保险人**指定的药店**（释义三十）自取并实时结算；或在保险人**认可的药店**（释义三十一）购药后凭发票申请理赔。

**逐字引用末段药品资质要求**：

> 「每次院外药品的处方剂量不得超过30天，且药品需为本合同期满日前在中国国家药品监督管理局批准且已在中国（不包括港澳台地区）上市的」

### 院外购药对客户案例的意义

| 维度 | 条款规定 | 实务要点 |
|---|---|---|
| **可挂的责任档** | 仅限「一般医疗 / 重疾医疗 / 指定疾病特需」三档 | 质子重离子、重疾津贴 不适用院外购药 |
| **必须有「住院」前提？** | 条款原文：「若无法在本次住院医院内获得」 | 严格读：要先有一次住院 + 出院带药才能触发；门诊单独购药能否走需进一步与保险人确认（这是常见纠纷点） |
| **药品资质** | NMPA 已批准 + 已在中国大陆上市 | 排除：仿制药未上市的、港澳代购、印度代购、临床试验阶段药、特批进口药 |
| **审核必经** | 授权申请 + 处方审核 | 客户**不能自己先买再报销**，必须先申请、先审核、再购药；事后补单大概率被拒 |
| **指定药店** | 保险人指定 or 认可药店 | 实务中通常是与众安合作的 DTP 药房（思派、上药云健康、镁信健康等），需向客服索取最新名单 |
| **处方剂量** | 单次 ≤ 30 天 | 长期治疗需多次申请 |

### 客户原话的潜在误解 — 「院外的也可以报销」

客户说"院外的也可以报销"，可能存在两种理解：

1. **正确理解**：保单确实有院外购药条款，但**有严格的授权流程 + 指定药店要求**，不是「随便去任何药房买、拿发票就报」。
2. **错误理解**：以为白血病的所有院外治疗费用（包括 CAR-T、中药、骨髓库配型费、未上市新药等）都能报。

**给客户的话术建议**：
- 不要直接说「能报」或「不能报」，先问清第二节 2.3 的 5 个问题。
- 强调「**报销前必须先向众安提出院外购药授权申请，得到处方审核通过 + 购药凭证后**才能去指定药店买药」。
- 提醒「未上市的进口药、临床试验药、港澳台药品**一律不在保障范围内**」。

## 五、还需要核对的潜在「拒赔陷阱」

| 风险点 | 条款位置 | 应对 |
|---|---|---|
| **既往症拒赔** | 第十条（一）（PDF Page 11, 合同全文.md L693-699）：「被保险人所患既往症及保险单中特别约定的除外疾病引起的相关费用」 | 查患者首次就诊/确诊日期 vs 保单生效日 |
| **等待期内确诊拒赔** | 同上：「等待期内接受检查但在等待期后确诊的同一种疾病」 | 等待期通常 30 日（需查保单具体条款），若在等待期内做过血常规/骨穿等检查，即使等待期后确诊也拒赔 |
| **不保证续保** | 第十二条（PDF Page 12, 合同全文.md L776-786）：「本合同为不保证续保合同……保险期间届满，投保人需要重新向保险人申请投保本产品，并经保险人同意」 | 确认本年度保单是否仍在保险期间内 |
| **未结算住院的延续期** | 第六条第一款（PDF Page 7, 合同全文.md L241-244）：「最高不超过本合同满期日后 30 日内的住院医疗费用」 | 若保单到期后还在住院，保险人续付 30 日，超过部分自负 |
| **免赔额** | 第八条（PDF Page 11, 合同全文.md L607-637）：好医保住院医疗一般免赔额 1 万元（具体以保单页为准） | 1 万元以下医疗费自负；从基本医保获得的补偿不可抵扣免赔额 |
| **医疗费用补偿原则** | 第九条（PDF Page 11, 合同全文.md L660-682）：「若被保险人已从其他途径获得医疗费用补偿，则保险人仅对……扣除其所获医疗费用补偿后的余额按照本合同的约定进行赔付」 | 已用社保 / 大病保险 / 其他商保报销过的部分，不能在好医保重复报销 |

## 六、下一步行动建议（给岩育同事）

1. **向 Luke 总索取**以下材料的扫描件 / 照片：
   - 患者**身份证 + 投保人 / 被保险人**关系证明
   - **好医保电子保单页**（含起保日期、保障档次、是否投了"指定疾病及手术特需医疗"可选责任、免赔额、保额）
   - **首次就诊和首次确诊的医院诊断书 + 病理报告**（含 ICD 编码、白血病亚型、分期）
   - **当前处方清单**（特别是患者所说的"院外药品"具体是哪些）
   - **历次理赔记录**（包括基本医保、大病保险、其他商保的报销凭证）

2. **核对关键时间线**：
   - 保单生效日 → 等待期结束日（投保前已患的，全部走既往症拒赔）
   - 患者首次确诊日 → 是否落在保险期间内
   - 当前是否仍在保险期间

3. **对应到具体责任档**：
   - 若首次确诊在保险期间内 → 走「重大疾病医疗保险金」+「重大疾病津贴保险金」
   - 若是 Binet A 期 CLL → 走「一般医疗保险金」（化疗/靶向 仍可门诊报销）
   - 若投保了「指定疾病特需」可选责任 → 可扩展至特需医疗机构

4. **院外购药**：
   - 确认所需药品是否在 NMPA 批准目录
   - 联系众安客服索取**保险人指定/认可药店名单**
   - 走授权申请 → 处方审核 → 购药 三步流程，**不要先买后报**

5. **若已踩既往症 / 等待期陷阱**：
   - 这份好医保已无法报销
   - 评估是否还有其他在保的商保或惠民保（部分惠民保对既往症有专门责任）

## 附录 B：本次抽取意外发现的工具 bug（已修复）

`000System/tools/OCR/ocr_multi.py` 的 `OCREngine._init_auto()` 原本会**预先实例化所有 4 个后端**，包括加载 RapidOCR ONNX 模型（10-60 秒）。即使百度 OCR 完全够用，每次构造 `OCREngine()` 仍需等待 RapidOCR 初始化。这是 PDF 抽取脚本第一次跑时挂住的根本原因。

修复方案：改为 **lazy init** —— `_init_auto()` 只实例化第一个能用的 backend，其余存入 `_pending` 列表；当 `ocr_bytes()` 中前一个 backend 失败时才实例化下一个。修复后 `OCREngine()` 构造时间从 60 秒+ 降到 1.5 秒。同时顺手清理了 dead import、ATOM_TYPE 标记、emoji、Baidu QPS 限流时机错误等 8 处问题（详见 `git diff`）。
